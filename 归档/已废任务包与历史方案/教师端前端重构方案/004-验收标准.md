# 验收标准

重构完成后，满足以下 4 点即可视为达标。

## 1. 单点可复现

- 刷新 S3 或 S4 页面后，不会掉回首页
- 依靠路由和 Store 缓存，能继续当前修改

## 2. 流程清晰

- 教师能清楚知道自己处在：
  - 确定意图
  - 补充资料
  - 生成大纲
  - 版本微调 / 导出

## 3. 模块隔离

- 学情分析等辅助模块作为独立 Tab 或侧边栏存在
- 不打断主体课件生成流程

## 4. 演示效果

- 页面布局专业、层次分明
- 呈现标准的 AI 教学工作台产品形态

## 建议验收清单

- 路由切换正常
- 页面刷新不丢状态
- S1-S4 数据可以透传
- API 结构和 Store 字段对齐
- AppShell 作为统一容器生效
