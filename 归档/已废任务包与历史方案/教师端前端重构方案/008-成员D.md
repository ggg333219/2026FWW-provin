**响应格式 (history)**


**响应格式 (load)**
```json
{
  "version_number": 3,
  "id": "uuid",

  "created_at": "..."

```

**前端文件**

### 2. 修改指令 Schema

**后端 API**

| 端点 | 方法 | 说明 |
|------|------|------|
| `/gen/modify` | POST | 提交修改命令 |

**请求体**
```json
{
  "nodes": [
    { "node_id": "node_001", "title": "...", "content": "...", "node_type": "slide" }
  ],
  "commands": [
    {
      "type": "update_node",
      "node_id": "node_001",
      "content": "修改后的内容"
    },
    {
      "type": "add_node",
      "after_node_id": "node_001",
      "content": "新节点内容"
    },
    {
      "type": "delete_node",
      "node_id": "node_002"
    },
    {
      "type": "swap_nodes",
      "node_ids": ["node_001", "node_002"]
    },
    {
      "type": "change_template",
      "template_id": "compact"
    }
  ],
  "regenerate": false
}
```

**命令类型清单**
| 类型 | 参数 | 说明 |
|------|------|------|
| `update_node` | `node_id`, `content` | 替换节点内容 |
| `add_node` | `after_node_id`, `content` | 插入新节点 |
| `delete_node` | `node_id` | 删除节点 |
| `swap_nodes` | `node_ids: [a, b]` | 交换两节点位置 |
| `change_template` | `template_id` | 切换样式模板 |
| `merge_nodes` | `node_ids` | 合并多个节点 |
| `split_node` | `node_id`, `split_point` | 拆分节点 |

**前端流程**
1. 用户在版本管理面板选择命令类型 + 输入节点 ID → 添加待处理修改
2. 积累修改后点"提交修改到后端" → `versionStore.submitModify(genId)`
3. Store 从 `currentVersionDetail.nodes` 取当前节点 → 连同 commands 一起 POST 到 `/gen/modify`
4. 成功后刷新版本列表（后端会生成新版本）

### 3. 导出任务状态

**后端 API**

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/v1/export/{gen_id}` | POST | 创建导出任务 `{"format":"pptx|docx|both","version":3}` |
| `/api/v1/export/status/{job_id}` | GET | 查询导出状态 |

**导出状态机**
```
PENDING → EXPORTING → DONE
                   → FAILED
```

**响应格式 (create)**
```json
{ "job_id": "exp_abc123", "status": "pending", "download_url": null, "error": null }
```

**响应格式 (status)**
```json
{ "job_id": "exp_abc123", "status": "done", "download_url": "/download/exp_abc123.pptx", "error": null }
```

**前端状态转换**
| store 值 | 后端状态 | UI 表现 |
|----------|---------|---------|
| `pending` | PENDING | 进度条动画，按钮禁用 |
| `exporting` | EXPORTING | 进度条动画，按钮禁用 |
| `done` | DONE | ✅ 导出完成，显示下载按钮 |
| `failed` | FAILED | ❌ 显示错误信息，可重试 |
| | `idle` | 初始状态，可用于重试 |

**前端轮询逻辑** (`versionStore._pollExport()`)
- 最多轮询 30 次，每次 2 秒间隔
- 状态为 `done` 或 `failed` 时停止
- 超时后标记为 `failed`

**前端文件**
- 组件: `src/components/teacher/S4VersionExportCenter.vue`
- 逻辑: `versionStore.startExport()` → `exportCreate()` → `_pollExport()` → `exportStatus()`

**前端数据流**
```
analyticsStore.loadStats(courseId)
  → teacherV1Api.analytics.getStats(courseId)
  → 规范化到 studentStats（含 masteryRadar / classTrend / learningInsights）

analyticsStore.loadCardData(courseId)
  → cardData[] 每项 { page, 提问量, 停留时长, 需重讲, 卡点指数 }

analyticsStore.loadQuestionRecords(courseId)
  → questionRecords[] 展示在提问记录表（支持分页 + 页码筛选）
```

**前端组件**
- 面板: `src/components/teacher/AnalyticsAndQuestionsPanel.vue` — 四合一面板
- 页面: `src/pages/AnalyticsPage.vue` — 独立路由 `/analytics`
- Store: `src/stores/analyticsStore.js`
- API: `src/services/v1/analyticsApi.js`
