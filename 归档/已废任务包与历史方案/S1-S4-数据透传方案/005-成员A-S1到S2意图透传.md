# 成员 A 任务说明

## 职责定位

S1 → S2 意图透传负责人。负责让 S1 确认的意图数据自动带到 S2 的知识库搜索入口。

## 目标

- S1 意图确认后，自动持久化到 localStorage
- S2 页面加载时，自动从 localStorage 读取并预填搜索框
- 刷新页面后数据不丢失

## 前置条件

- `intentStore.parsedIntent` 已有完整数据（topic、subject、learningObjectives、grade 等）
- `KnowledgeBasePanel` 已有搜索功能（`searchQuery` ref 控制搜索框内容）
- 无其他依赖

## 涉及文件

### 文件 1：`src/pages/S1IntentPage.vue`

**改动位置**：`<script setup>` 部分，intentStore 相关逻辑之后

**改动内容**：添加 watcher，监听 `intentStore.parsedIntent` 的变化，当意图确认后写入 localStorage。

```javascript
// 添加位置：在 store 初始化之后，其他逻辑之前
import { watch } from 'vue'

// 当 parsedIntent 变化时写入 localStorage
watch(() => intentStore.parsedIntent, (val) => {
  if (val && val.topic) {
    // 只写入有实际内容的意图
    localStorage.setItem('fuww_intent_parsed', JSON.stringify(val))
  }
}, { deep: true })
```

**注意事项**：
- 不要重复写入相同的 intent（加一个简单去重）
- 只在 intent 有实际内容时写入（topic 非空）
- 不要阻塞主流程

### 文件 2：`src/components/teacher/KnowledgeBasePanel.vue`

**改动位置**：`<script setup>` 中 `onMounted` 部分，或添加一个新的 `onMounted` 钩子

**改动内容**：在组件挂载时从 localStorage 读取 intent 数据，如果搜索框为空且有 intent 数据，则自动填入搜索框并触发搜索。

```javascript
// 添加位置：在 onMounted 中，其他初始化逻辑之后
import { onMounted } from 'vue'

onMounted(() => {
  // 如果搜索框为空，尝试从 localStorage 恢复 intent 数据
  if (!searchQuery.value) {
    try {
      const raw = localStorage.getItem('fuww_intent_parsed')
      if (raw) {
        const intent = JSON.parse(raw)
        // 构造搜索关键词：topic + subject
        const keywords = [intent.topic, intent.subject]
          .filter(Boolean)
          .join(' ')
        if (keywords) {
          searchQuery.value = keywords
          // 自动触发搜索
          handleSearch()
        }
      }
    } catch (e) {
      console.warn('[KnowledgeBasePanel] 恢复 intent 数据失败', e)
    }
  }
})
```

**注意事项**：
- 只在搜索框为空时填入，不覆盖用户手动输入
- JSON.parse 可能失败，需要 try-catch
- 不要阻塞组件渲染

## 数据契约

### localStorage Key

| Key | 类型 | 写入时机 | 读取时机 |
|-----|------|---------|---------|
| `fuww_intent_parsed` | JSON string | intentStore.parsedIntent 变化且 topic 非空 | KnowledgeBasePanel mounted |

### 数据格式

```json
{
  "topic": "二次函数图像性质",
  "grade": "九年级",
  "subject": "数学",
  "learningObjectives": "掌握二次函数开口方向、对称轴、顶点坐标",
  "difficulty": "中等",
  "estimatedDuration": 45,
  "prerequisite": "一次函数基础"
}
```
