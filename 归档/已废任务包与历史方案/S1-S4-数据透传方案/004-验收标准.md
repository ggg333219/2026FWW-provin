# 验收标准

数据透传整合完成后，满足以下 4 点即可视为达标。

## 1. S1 → S2 意图透传达标

- [ ] S1IntentPage 中确认/锁定意图后，localStorage 中出现 `fuww_intent_parsed`
- [ ] 跳转到 S2MaterialPage 后，KnowledgeBasePanel 搜索框自动填入 intent 内容
- [ ] 刷新 S2 页面后，搜索框仍然有内容
- [ ] 无意图数据时（首次进入 S2），搜索框正常显示 placeholder，不报错

## 2. S2 → S3 证据透传达标

- [ ] S2 中绑定证据后，localStorage 中出现 `fuww_s2_evidence_packet`
- [ ] S3StudioPage 调用 AI 生成时，证据包作为额外参数传入
- [ ] 无证据数据时，S3 生成请求正常发起（不附加证据，不报错）
- [ ] 后端接到证据参数后，响应时间无异常增加

## 3. S3 → S4 gen_id 透传达标

- [ ] S3 生成完成后，`generationStore.lastGenId` 正确设置
- [ ] localStorage 中出现 `fuww_last_gen_id`
- [ ] S4VersionPage 加载时，gen_id 输入框自动填充
- [ ] 刷新 S4 页面后，gen_id 仍然自动填充
- [ ] 无 gen_id 数据时，S4 页面正常显示空状态，不报错

## 4. WorkspacePage 跨 Tab 编排达标

- [ ] intent Tab → material Tab 切换：搜索框自动填充
- [ ] material Tab → script Tab 切换：证据自动传递
- [ ] script Tab → version Tab 切换：gen_id 自动填入
- [ ] 刷新后所有 Tab 间透传仍然有效
- [ ] Tab 切换时无页面报错

## 5. 整体流程达标

- [ ] 完整走通 S1 → S2 → S3 → S4 流程
- [ ] 任意步骤刷新后数据不丢失
- [ ] Mock 模式下也能正常透传
- [ ] 浏览器控制台无错误日志
- [ ] 所有透传使用 `fuww_` 前缀的 localStorage key

## 6. 不影响已有功能

- [ ] S1 原有功能不变（对话、摘要、锁定）
- [ ] S2 原有功能不变（上传、解析、RAG 检索）
- [ ] S3 原有功能不变（生成、编辑、预览）
- [ ] S4 原有功能不变（版本列表、修改指令、导出）
- [ ] WorkspacePage 原有 Tab 功能不变
