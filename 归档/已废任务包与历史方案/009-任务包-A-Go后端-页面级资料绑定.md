### A-1. DTO 新增 `PageEvidenceBinding` / `PageUploadSlot` ⭐

**目标**：与 Python 端 §2.3.1 数据模型同步（**字段名严格对齐 B 类实现**），同时保留旧 `evidence_packet` 字段兼容。

**文件**：
- 扩展：`backend/internal/service/models.go`

**实现要点**：
```go
// 新增类型
type PageEvidenceBinding struct {
    PageID      string    `json:"page_id"`
    EvidenceRefs []string `json:"evidence_refs"`
    AutoBound   bool      `json:"auto_bound"`
    BoundAt     time.Time `json:"bound_at"`
    BoundBy     string    `json:"bound_by"` // "system:intent_keyword" | "user:<teacher_id>"
}

type PageUploadSlot struct {
    PageID          string   `json:"page_id"`
    UploadSessionID string   `json:"upload_session_id"`
    Chunks          []Chunk  `json:"chunks"`
    Selected        bool     `json:"selected"`
}

// 新增请求/响应
type AutoBindPagesRequest struct {
    IntentID       string  `json:"intent_id" binding:"required"`
    OutlineID      string  `json:"outline_id" binding:"required"`
    TopKPerPage    int     `json:"top_k_per_page"`     // 默认 5
    MinScore       float64 `json:"min_score"`          // 默认 0.2
}

type AutoBindPagesResponse struct {
    PageBindings  map[string]PageEvidenceBinding `json:"page_bindings"`  // page_id → binding
    MissingPages  []string                       `json:"missing_pages"`
}

type RegeneratePageRequest struct {
    PageID         string   `json:"page_id" binding:"required"`
    GenerationID   string   `json:"generation_id" binding:"required"`
    OutlineID      string   `json:"outline_id" binding:"required"`
    EvidenceRefs   []string `json:"evidence_refs"`
    UserInstruction string  `json:"user_instruction"`
}
```

**验证**：
- `go build ./...` 通过
- `go vet ./...` 通过
- 单测 `backend/internal/service/models_test.go` 验证 JSON 序列化/反序列化（用 `encoding/json` Marshal/Unmarshal 一轮）

**完成标志**：
- 与 B 类的 Pydantic schema 字段名严格一致（`page_id` / `evidence_refs` / `auto_bound` / `bound_at` / `bound_by`）

### A-4. `VersionHandler` 快照包含 `pageBindings` ⭐（用户已确认）

**目标**：版本快照字段从"仅 generation 内容"扩展为"+ pageBindings"，rollback 后绑定关系一并恢复。

**文件**：
- 扩展：`backend/internal/handler/version_handler.go`
- 新增：`backend/internal/service/version_service.go`（如已有则扩展）新增 `SnapshotPageBindings(outline_id string) (map[string]PageEvidenceBinding, error)` 与 `RestorePageBindings(outline_id string, bindings map[string]PageEvidenceBinding) error`

**实现要点**：
1. Snapshot 时机：每次 `generation` 锁定（大纲/内容/样式 三门确认时）、每次 `version_save` 触发
2. 数据来源：调 B-3 的 `get_page_bindings(outline_id)` 取当前 Redis 数据
3. 存储位置：写入 Postgres `version_snapshots.page_bindings JSONB` 字段（如表结构无此字段需 `ALTER TABLE` 迁移）
4. Restore 时机：rollback 时把快照里的 `page_bindings` 写回 Redis
5. **数据迁移**：对已有 version_snapshots，`page_bindings` 字段默认为 `{}`，回滚时不报错

**验证**：
- 单测 `backend/internal/handler/version_handler_test.go`：
  - RED：mock `ai_engine_client.GetPageBindings` 返回 3 个 page 的 bindings → snapshot → 验证版本记录里 `page_bindings` 字段非空
  - RED：rollback → 验证 mock `ai_engine_client.SetPageBindings` 被调用并传入相同 bindings
  - RED：旧快照（`page_bindings=null`）→ rollback 不报错
  - GREEN：实现直到通过
- 迁移：`ALTER TABLE version_snapshots ADD COLUMN IF NOT EXISTS page_bindings JSONB DEFAULT '{}'`

**完成标志**：
- C-7 的 S4 rollback 路径能恢复 pageBindings
