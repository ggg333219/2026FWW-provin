## 4. 下一轮迭代核心目标与开发原则

### 4.1 唯一核心目标

**打通 S1意图 -> S2素材 -> S3生成 -> S4版本 -> 预览 -> 导出 完整可演示闭环，真实跑通一次端到端，导出文件在WPS中正常打开。**

### 4.2 全员统一开发原则

1. **P0优先合入**：questions类型统一(P0-1)和normalize合并(P0-2)必须立即修复，不等其他任务。
2. **禁止跨模块改动**：成员只改本人模块代码，跨模块依赖通过接口约定协同，不得强行修改他模块文件。
3. **每步必测**：每一项开发完成后执行对应自测，不允许"代码提交但功能未验证"。
4. **联调不等人**：成员完成本人任务后主动通知下游成员，不等待定期会议。
5. **主干链路优先**：所有非P0/P1任务本轮全部暂停，不投入开发资源。
6. **不出局不合并**：py_compile有语法错误不得合并，主干测试有新增失败不得合并。

## 7. 故障风险应对预案

### 7.1 LLM 阻塞/超时预案

**触发场景**：LLM服务端响应超过90s，daemon线程夯死

**应对流程**：
1. 设置全局timeout=90s，超时后LLMClient.chat抛出TimeoutException
2. daemon线程捕获TimeoutException，任务状态标记为failed
3. 前端/gen/status轮询拿到status=failed，显示"生成超时，请重试"
4. 用户重新发起/gen/create

**预防措施**：
- T2-P1c增加timeout保护（见任务拆分）
- T4-P1增加daemon线程超时监控日志

### 7.2 Redis 降级异常预案

**触发场景**：Redis连接失败（网络抖动/服务重启）

**应对流程**：
1. RedisTaskStore自动降级为_InMemoryTaskStore
2. /health返回{"redis":false,"mode":"memory"}
3. 运维收到告警后检查Redis服务
4. Redis恢复后，内存中新任务不自动同步（已有磁盘快照不受影响）

**预防措施**：
- 已有磁盘快照（data/versions/）不受Redis故障影响
- 重要课件定期检查磁盘快照存在性

### 7.3 字段格式不匹配预案

**触发场景**：新节点写入后预览/导出时某个字段读取结果为空

**应对流程**：
1. 确认是哪个字段不匹配（检查data/versions/{gen_id}/v_N.json）
2. 判断是normalize丢失还是写入时缺失
3. 如果是normalize丢失，在对应normalize函数补充字段映射
4. 如果是写入时缺失，在对应_handle_add或生成器补充字段

**预防措施**：
- T1-P0修复P0-1+P0-2，消除最常见的类型冲突
- T1-P1实现core_points/key_points双向同步

### 7.4 预览-导出内容不一致预案

**触发场景**：预览HTML正常但导出PPTX后内容或排版与预览不符

**应对流程**：
1. 对比preview.py和export_ppt.py对同一字段的读取逻辑
2. 优先以preview.py渲染结果为正确基准（已通过真实LLM验证）
3. 修改export_ppt.py对齐preview.py的字段读取顺序
4. 用同一gen_id分别调用预览接口和导出接口，对比内容差异

**预防措施**：
- 导出前先保存版本快照，用同一版本快照做预览和导出
- T3-P1b验证MinIO导出URL可正确获取文件

```python
def _add_two_column_slide(self, prs: Presentation, node: dict) -> None:
    """
    双栏内容页。
    左栏：key_points 要点列表
    右栏：segments 分段内容（优先）或 content/script
    """
    node = _as_mapping(node)
    # 使用 BLANK 布局或自定义 TWO_COLUMN 母版
    slide = prs.slides.add_slide(prs.slide_layouts[6])
    if slide.shapes.title:
        slide.shapes.title.text = node.get("title", "")

    kps = resolve_key_points(node)

    # 左栏（要点）
    left_box = slide.shapes.add_textbox(Inches(0.5), Inches(1.5), Inches(5.8), Inches(5.5))
    left_tf = left_box.text_frame
    left_tf.word_wrap = True
    for pt in (kps or [])[:8]:
        p = left_tf.add_paragraph()
        p.text = f"* {pt}"
        p.font.size = Pt(18)

    # 右栏（分段内容）
    right_box = slide.shapes.add_textbox(Inches(6.5), Inches(1.5), Inches(6.3), Inches(5.5))
    right_tf = right_box.text_frame
    right_tf.word_wrap = True
    segments = node.get("segments") or []
    if segments:
        for seg in segments[:4]:
            seg_type = seg.get("segment_type", "")
            seg_text = seg.get("text", "")[:80]
            p = right_tf.add_paragraph()
            p.text = f"[{seg_type}] {seg_text}"
            p.font.size = Pt(14)
    else:
        content = (node.get("content") or node.get("script") or "")[:300]
        p = right_tf.add_paragraph()
        p.text = content
        p.font.size = Pt(16)
```

```python
def acquire(self, max_retries: int = 3) -> bool:
    import time as _time
    client = _get_redis_client()
    if client is None:
        return False
    import uuid as _uuid
    token = str(_uuid.uuid4())
    delay = 0.1  # 100ms
    for attempt in range(max_retries):
        try:
            ok = client.set(self.key, token, nx=True, ex=self.ttl)
            if ok:
                self._token = token
                return True
        except Exception:
            pass
        if attempt < max_retries - 1:
            _time.sleep(delay)
            delay *= 2  # 100ms -> 200ms -> 400ms
    return False
```

```python
def _paginate_by_paragraphs(self, node: dict, paragraphs: list, title_base: str, page_count: int) -> list[PaginatedNode]:
    """按段落边界拆分，保证每页段落语义完整。"""
    import math
    if page_count <= 0:
        page_count = 1

    n_paras = len(paragraphs)
    if n_paras == 0:
        return [PaginatedNode(
            index=1, total=1,
            title=title_base, content="",
            key_points=[], segments=[],
            node_type=str(node.get("type") or node.get("node_type") or "content"),
            layout_hint=node.get("layout_hint"),
            font_size_hint=node.get("font_size_hint"),
        )]

    paras_per_page = math.ceil(n_paras / page_count)
    pages: list[PaginatedNode] = []

    for pg in range(page_count):
        start = pg * paras_per_page
        end = min(start + paras_per_page, n_paras)
        page_paras = paragraphs[start:end]
        if not page_paras:
            continue
        # 在段落边界（

）拼接，保证语义完整
        content = "

".join(str(p).strip() for p in page_paras if str(p).strip())
        title_suffix = f"（{pg + 1}/{page_count}）" if page_count > 1 else ""
        pages.append(PaginatedNode(
            index=pg + 1,
            total=page_count,
            title=f"{title_base}{title_suffix}",
            content=content,
            key_points=[],
            segments=[],
            node_type=str(node.get("type") or node.get("node_type") or "content"),
            layout_hint=node.get("layout_hint"),
            font_size_hint=node.get("font_size_hint"),
        ))
    return pages
```
