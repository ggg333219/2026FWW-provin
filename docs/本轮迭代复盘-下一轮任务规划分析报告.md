## 4. 下一轮迭代核心目标与开发原则

### 4.1 唯一核心目标

**打通 S1意图 -> S2素材 -> S3生成 -> S4版本 -> 预览 -> 导出 完整可演示闭环，真实跑通一次端到端，导出文件在WPS中正常打开。**

### 4.2 全员统一开发原则

1. **P0优先合入**：questions类型统一(P0-1)和normalize合并(P0-2)必须立即修复，不等其他任务。
2. **禁止跨模块改动**：成员只改本人模块代码，跨模块依赖通过接口约定协同，不得强行修改他模块文件。
3. **每步必测**：每一项开发完成后执行对应自测，不允许"代码提交但功能未验证"。
4. **联调不等人**：成员完成本人任务后主动通知下游成员，不等待定期会议。
5. **主干链路优先**：所有非P0/P1任务本轮全部暂停，不投入开发资源。
6. **不出局不合并**：py_compile有语法错误不得合并，主干测试有新增失败不得合并。

## 7. 故障风险应对预案

### 7.1 LLM 阻塞/超时预案

**触发场景**：LLM服务端响应超过90s，daemon线程夯死

**应对流程**：
1. 设置全局timeout=90s，超时后LLMClient.chat抛出TimeoutException
2. daemon线程捕获TimeoutException，任务状态标记为failed
3. 前端/gen/status轮询拿到status=failed，显示"生成超时，请重试"

### 7.2 Redis 降级异常预案

**触发场景**：Redis连接失败（网络抖动/服务重启）

**应对流程**：
1. RedisTaskStore自动降级为_InMemoryTaskStore
2. /health返回{"redis":false,"mode":"memory"}
3. 运维收到告警后检查Redis服务
4. Redis恢复后，内存中新任务不自动同步（已有磁盘快照不受影响）

**预防措施**：
- 已有磁盘快照（data/versions/）不受Redis故障影响
- 重要课件定期检查磁盘快照存在性

### 7.3 字段格式不匹配预案

4. 如果是写入时缺失，在对应_handle_add或生成器补充字段

**预防措施**：

**阶段二：编写迁移脚本**

在 `ai_engine/gen/` 下新建 `migrate_snapshot.py`：

```python
"""
旧版本快照 schema 迁移工具

将旧版 TeachingNode 快照字段迁移为当前 schema 标准。
"""
import json
import os
from pathlib import Path

CURRENT_FIELDS = {
    'node_id', 'title', 'node_type', 'type', 'summary',
    'key_points', 'core_points', 'questions', 'interactive_questions',
    'segments', 'layout_hint', 'font_size_hint', 'text_alignment',
    'slide_background', 'content', 'script', 'source_span',
    'prerequisites', 'page_ref', 'source_chunk_ids',
    'examples', 'key_difficulties', 'expected_outcomes',
    'estimated_duration_minutes', 'citation_refs',
    'next_node_id', 'prev_node_id', 'metadata',
}

def migrate_node(node: dict) -> dict:
    """补充缺失字段，返回迁移后的节点。"""
    for field in CURRENT_FIELDS:
        if field not in node:
            if field in ('key_points', 'core_points', 'questions',
                         'interactive_questions', 'segments', 'prerequisites',
                         'examples', 'key_difficulties', 'citation_refs',
                         'source_chunk_ids'):
                node[field] = []
            elif field in ('layout_hint', 'font_size_hint',
                            'text_alignment', 'slide_background', 'node_type',
                            'type', 'source_span', 'content', 'script',
                            'next_node_id', 'prev_node_id', 'page_ref',
                            'estimated_duration_minutes'):
                node[field] = None
            elif field == 'metadata':
                node[field] = {}
    # 兼容：type 和 node_type 至少有一个
    if not node.get('type') and node.get('node_type'):
        node['type'] = node['node_type']
    if not node.get('node_type') and node.get('type'):
        node['node_type'] = node['type']
    return node

def migrate_file(filepath: str) -> bool:
    """迁移单个快照文件。返回是否实际修改了内容。"""
    with open(filepath, 'r', encoding='utf-8') as f:
        data = json.load(f)
    original = json.dumps(data, ensure_ascii=False)
    nodes = data.get('nodes_snapshot', [])
    for i, node in enumerate(nodes):
        nodes[i] = migrate_node(dict(node))
    migrated = json.dumps(data, ensure_ascii=False)
    if migrated != original:
        with open(filepath, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
        return True
    return False

def main():
    base = Path('data/versions')
    migrated = 0
    for ver_dir in base.iterdir():
        if not ver_dir.is_dir():
            continue
        for snap_file in ver_dir.glob('v_*.json'):
            try:
                if migrate_file(str(snap_file)):
                    print(f'迁移: {snap_file}')
                    migrated += 1
            except Exception as e:
                print(f'错误: {snap_file}: {e}')
    print(f'共迁移 {migrated} 个文件')

if __name__ == '__main__':
    main()
```

def _add_two_column_slide(self, prs: Presentation, node: dict) -> None:
    """
    双栏内容页。
    左栏：key_points 要点列表
    右栏：segments 分段内容（优先）或 content/script
    """
    from pptx.util import Inches, Pt
    node = _as_mapping(node)
    slide = prs.slides.add_slide(prs.slide_layouts[6])
    if slide.shapes.title:
        slide.shapes.title.text = node.get("title", "")

    kps = resolve_key_points(node)

    # 左栏（要点）
    left_box = slide.shapes.add_textbox(Inches(0.5), Inches(1.5), Inches(5.8), Inches(5.5))
    left_tf = left_box.text_frame
    left_tf.word_wrap = True
    for pt in (kps or [])[:8]:
        p = left_tf.add_paragraph()
        p.text = f"* {pt}"
        p.font.size = Pt(18)

    # 右栏（分段内容）
    right_box = slide.shapes.add_textbox(Inches(6.5), Inches(1.5), Inches(6.3), Inches(5.5))
    right_tf = right_box.text_frame
    right_tf.word_wrap = True
    segments = node.get("segments") or []
    if segments:
        for seg in segments[:4]:
            seg_type = seg.get("segment_type", "")
            seg_text = (seg.get("text") or "")[:80]
            p = right_tf.add_paragraph()
            p.text = f"[{seg_type}] {seg_text}"
            p.font.size = Pt(14)
    else:
        content = (node.get("content") or node.get("script") or "")[:300]
        p = right_tf.add_paragraph()
        p.text = content
        p.font.size = Pt(16)

### T4-P1：分布式锁指数退避重试 + PID死锁恢复

**阶段二：实施修改**

**步骤A**：修改 `_RedisLock.acquire` 增加指数退避

找到 `acquire` 方法，改造为：

```python
def acquire(self, max_retries: int = 3) -> bool:
    import time as _time
    import uuid as _uuid
    client = _get_redis_client()
    if client is None:
        return False
    token = str(_uuid.uuid4())
    delay = 0.1  # 100ms
    for attempt in range(max_retries):
        try:
            ok = client.set(self.key, token, nx=True, ex=self.ttl)
            if ok:
                self._token = token
                return True
        except Exception:
            pass
        if attempt < max_retries - 1:
            _time.sleep(delay)
            delay *= 2  # 100ms -> 200ms -> 400ms
    return False
```

**步骤B**：修改 `_DistributedLock` 增加 PID 追踪

在 `__init__` 中添加：
```python
self._llock_pid = os.getpid()
```

在 `__enter__` 中添加 PID 检测：
```python
def __enter__(self) -> "_DistributedLock":
    current_pid = os.getpid()
    if current_pid != self._llock_pid:
        # 进程已重启，重置本地锁
        self._llock = _lock_for(self._gen_id)
        self._llock_pid = current_pid
    if self._rlock.acquire(max_retries=3):
        self._using_redis = True
        return self
    self._llock.acquire()
    self._using_redis = False
    return self
```
