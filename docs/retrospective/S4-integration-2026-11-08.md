## 根因与解决方案

### 数据不可见

Go 曾连接 `teaching_test`，而历史课件在原 `teaching`。解决方式是创建专用验收副本并将 Go 指向该副本，未覆盖原数据库。

### 元素定位追问

历史课件恢复后，前端选中节点状态未始终同步到修改 Store；Python 因缺少可靠的活动页上下文而进入澄清路径。修复恢复时的节点同步、节点失效清理和旧追问清理，同时保留真正歧义的追问逻辑。

### LLM 认证失败

Windows 凭据注入的 Key 对当前服务商请求无效。捕获日志提供了原始 401 证据。通过 `.env.local` 明确注入用户自行维护的 Key，避免旧环境变量或旧凭据覆盖。

## 工程经验

- 健康检查 200 不能证明运行程序来自目标工作区；必须核对进程路径、启动目录、分支和请求代码路径。
- 数据库切换必须配套项目、草稿、版本和目标项目 ID 的只读核对。
- 异步接口必须验证任务持久化、轮询、幂等完成和失败不覆盖原数据。
- LLM 异常不能伪装成用户指令歧义；应保留脱敏原始错误证据。
- 本地模型配置与代码、数据库配置分离，密钥只放在被忽略的本机配置中。
