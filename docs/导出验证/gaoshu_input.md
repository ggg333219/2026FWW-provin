# 高等数学：极限与连续

极限是高等数学的第一块基石，后续的导数、积分、级数全部建立在极限语言之上。本节我们围绕"极限的定义、计算与连续性"三个层次展开。

## 数列的极限

对于数列 {a_n}，如果当 n 无限增大时 a_n 无限接近某个常数 A，就称 A 为数列的极限，记作 lim(n→∞) a_n = A。

- ε-N 定义：任意 ε>0，存在正整数 N，当 n>N 时 |a_n - A| < ε
- 直观理解：ε 是"精度要求"，N 是"从第几项开始达标"
- 收敛数列极限唯一，且数列有界；有界不一定收敛（反例：(-1)^n）

## 函数的极限

函数极限分两种情形：自变量趋于有限值（x→x0）与趋于无穷（x→∞）。

- x→x0 的极限：|f(x) - A| < ε 在 0 < |x - x0| < δ 上成立
- 左极限与右极限：lim(x→x0-) f(x) 与 lim(x→x0+) f(x)，二者相等才是极限存在的充要条件
- 无穷大与无穷小：极限为 0 的变量是无穷小；无穷小的倒数（分母非零）是无穷大

## 极限的计算方法

计算极限要掌握"先定型、再选法"的思路。

- 四则运算法则：极限存在的前提下才能拆分
- 两个重要极限：lim(x→0) sin x / x = 1；lim(x→∞) (1 + 1/x)^x = e
- 等价无穷小替换：x→0 时，sin x ~ x，tan x ~ x，ln(1+x) ~ x，1 - cos x ~ x²/2
- 洛必达法则：0/0 或 ∞/∞ 型可先化简再求导，注意使用前提是导数比的极限存在

例题：求 lim(x→0) (1 - cos x) / x²。
解：1 - cos x ~ x²/2，故原式 = (x²/2) / x² = 1/2。

## 函数的连续性

f(x) 在 x0 连续需满足三个条件：有定义、极限存在、极限值等于函数值。

- 间断点分类：可去间断点（极限存在但不等于函数值）、跳跃间断点（左右极限不等）、第二类间断点（无穷或振荡）
- 闭区间上连续函数的性质：有界性定理、最值定理、介值定理、零点定理
- 零点定理的应用：判断方程 f(x)=0 在区间内是否有根，是后续二分法求根的理论基础

## 小结

- 极限是描述"无限接近"的精确语言，ε-δ 是全部微积分的地基
- 计算极限先判断类型，再选择四则运算、两个重要极限、等价无穷小或洛必达
- 连续性把极限与函数值连接起来，闭区间连续函数的四个定理是证明题的常客
