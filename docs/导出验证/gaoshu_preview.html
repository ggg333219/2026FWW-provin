高等数学：极限与连续

\n

课程封面：说明极限是高等数学的基石，为后续导数、积分、级数提供语言基础。

\n
  • 极限是高等数学的第一块基石
  • 导数、积分、级数均建立在极限语言之上
  • 本课程围绕极限的定义、计算与连续性展开
\n

课程导言：三大学习层次

\n
  • 极限是描述无限接近的精确语言
  • 围绕极限的定义、计算与连续性三个层次展开
  • 为后续导数、积分、级数学习奠定基础
\n

引入极限与连续的整体脉络，强调从定义到计算、再到连续性应用的递进关系。

\n \n

讲授分段

  1. 导入⏱ 40秒🟢

    先看一个数列：1, 1/2, 1/3, 1/4, ... 当 n 越来越大，第 n 项 1/n 是不是越来越靠近 0？这个 0 就是它的极限。

    💬 谁能说出这个数列的极限是多少？

    📘 数列极限（直观）

    当 n 无限增大时，a_n 无限接近常数 A，则称 A 为数列的极限

    lim(n→∞) a_n = A
    数列直观
  2. 其他⏱ 30秒🟢

    注意‘无限接近’不等于‘等于’。比如 1/n 永远不等于 0，但它的极限是 0。这就是极限的微妙之处。

    💬 请同桌讨论：数列中是否有某一项等于极限值？

    📘 接近而未必到达

    极限描述的是趋势，而不是最终取值

    易错点
  3. 示例⏱ 45秒🟡

    再看一个例子：a_n = 2 + (-1)^n / n。当 n 增大时，a_n 会越来越接近 2。你能直观感受到极限是 2 吗？

    💬 写出前几项，观察趋势。

    📘 极限值

    数列变化趋势所逼近的常数

    lim(n→∞) (2 + (-1)^n/n) = 2
    例子
  4. 过渡⏱ 25秒🟡

    直观定义虽然好懂，但‘无限接近’这个词太模糊。为了精确，我们需要数学语言——这就是 ε-N 定义。

    💬 试着说出‘无限接近’在数学上可以怎么翻译。

    📘 精确化

    用任意小的正数 ε 来控制误差，从而严格表述极限

    方法

数列的极限

\n
  • lim(n→∞) a_n = A 表示 a_n 无限接近常数 A
  • ε-N 定义：任意 ε>0，存在 N，当 n>N 时 |a_n-A|<ε
  • ε 是精度要求，N 是从第几项开始达标
  • 收敛数列极限唯一且数列有界
  • 有界不一定收敛，反例为 (-1)^n
\n

定义数列极限的直观意义与ε-N精确语言，并讨论收敛数列的基本性质。

\n \n

讲授分段

  1. 导入⏱ 50秒🔴

    ε-N 定义是这样的：任意给定一个正数 ε，存在正整数 N，使得当 n > N 时，恒有 |a_n - A| < ε。

    💬 这是一个逻辑结构复杂的定义，请先记住‘任意’和‘存在’的具体含义。

    📘 ε-N 定义

    数列 a_n 收敛于 A：对任意 ε>0，存在 N，当 n>N 时 |a_n-A|<ε

    ∀ε>0, ∃N, ∀n>N: |a_n-A|<ε
    定义极限
  2. 示例⏱ 45秒🟡

    例如 a_n = 1/n，若要求 ε=0.01，那么 n>100 时 |1/n - 0| < 0.01，N 取 100 即可。

    💬 如果 ε=0.0001，N 该取多少？请口答。

    📘 N 的作用

    N 表示从第几项开始，数列项与极限的距离小于给定的 ε

    N = 100 for ε=0.01
    例子ε-N
  3. 互动⏱ 35秒🔴

    大家注意，ε 是可以任意小的正数，它代表精度要求；N 则随 ε 变化，ε 越小，N 通常就越大。

    💬 请同桌互相提问：如果 N 不随 ε 变化，极限还成立吗？

    📘 ε 与 N 关系

    N 依赖于 ε，ε 越小，N 一般越大，体现了‘无限接近’的动态过程

    N = N(ε)
    理解ε-N
  4. 过渡⏱ 20秒🟡

    理解了 ε 和 N，我们就能判断一个数列是否收敛。接下来看收敛数列有哪些基本性质。

    💬 回忆一下：收敛数列的极限是否唯一？

    📘 收敛数列性质

    收敛数列极限唯一且有界

函数的极限

\n
  • 函数极限分为 x→x0 与 x→∞ 两类
  • x→x0 时用 0<|x-x0|<δ 和 |f(x)-A|<ε 刻画
  • 左极限与右极限相等是极限存在的充要条件
  • 极限为 0 的变量称为无穷小
  • 无穷小的倒数（分母非零）是无穷大
\n

区分自变量趋于有限值与无穷两类极限，引入左右极限、无穷大与无穷小概念。

讲授分段

  1. 导入⏱ 35秒🟡

    收敛数列有一个重要性质：极限唯一。如果数列收敛，它不可能同时接近两个不同的常数。

    💬 为什么一个数列不能同时收敛到两个不同的数字？

    📘 极限唯一性

    收敛数列的极限必定唯一

    性质数列
  2. 其他⏱ 40秒🟡

    同时，收敛数列一定有界。因为从某一项之后所有项都挤在极限附近，而前面的有限项自然可以找到上下界。

    💬 请同学们尝试从定义出发，解释为什么收敛必有界。

    📘 收敛必有界

    若数列收敛，则数列必为有界数列

    性质证明
  3. 互动⏱ 40秒🟡

    但反过来，有界是否一定收敛？请看 (-1)^n：它在 1 和 -1 之间反复横跳，有界却又发散。

    💬 请判断：这个数列的极限是 1 还是 -1？

    📘 有界不一定收敛

    反例 (-1)^n 有界但发散

    (-1)^n
    反例易错
  4. 过渡⏱ 25秒🟢

    数列的‘离散’极限我们清楚了，接下来把它们推广到更自然的‘连续’情形——函数极限。

    💬 想想：数列与函数有什么不同？

    自变量连续变化时函数值的趋近趋势

极限的计算方法

\n
  • 计算极限应先判断类型，再选择方法
  • 极限存在的前提下才能拆分四则运算
  • 两个重要极限：lim sin x/x=1，lim(1+1/x)^x=e
  • x→0 时 sin x~x，tan x~x，ln(1+x)~x，1-cos x~x²/2
  • 洛必达法则适用于 0/0 或 ∞/∞ 型，需验证条件
\n

介绍“先定型、再选法”的计算思路，包括四则运算、两个重要极限、等价无穷小及洛必达法则。

讲授分段

  1. 导入⏱ 40秒🟢

    函数极限有两种基本变化趋势：自变量 x 越来越接近某个有限值 x0；或者 x 的绝对值无限增大，趋向正负无穷。

    💬 你能各举一个实际例子吗？

    📘 函数极限类型

    包括 x→x0 和 x→∞ 两类极限

    分类函数
  2. 示例⏱ 45秒🟡

    比如 x→0 时 sin x / x 的极限，和 x→∞ 时 (1+1/x)^x 的极限，分别对应两种类型。

    💬 观察这两个极限的区别在哪里。

    📘 两个重要极限

    lim(x→0) sin x/x 和 lim(x→∞)(1+1/x)^x

    lim(x→0) sinx/x=1; lim(x→∞)(1+1/x)^x=e
    例子重要极限
  3. 互动⏱ 35秒🟡

    大家想一想：为什么要同时研究两种？因为它们对应着不同的实际过程：一个是局部瞬时变化，一个是长期趋势。

    💬 请结合生活现象说明‘局部’和‘长期’的区别。

    📘 实际意义

    x→x0 用于瞬时变化，x→∞ 用于长期行为

    应用直觉
  4. 过渡⏱ 20秒🟡

    先看第一种，x→x0 的极限如何精确定义。

    💬 类比 ε-N，函数极限需要引入哪个量？

    📘 ε-δ 定义

    用 δ 控制 x 与 x0 的距离，用 ε 控制 f(x) 与 A 的距离

例题：求 lim(x→0)(1-cos x)/x²

\n
  • x→0 时 1-cos x ~ x²/2
  • 原式可化为 (x²/2)/x²
  • 极限值为 1/2
  • 体现等价无穷小替换的典型用法
\n

通过等价无穷小替换求解该典型极限，展示计算方法的实际运用。

\n \n

讲授分段

  1. 导入⏱ 60秒🔴

    仿照数列的 ε-N 语言，对函数 x→x0 的极限，我们使用 ε-δ 定义：任意 ε>0，存在 δ>0，当 0<|x-x0|<δ 时，|f(x)-A|<ε。

    💬 请注意：0<|x-x0| 表示 x 不能等于 x0。

    📘 ε-δ 定义

    对任意 ε>0，存在 δ>0，使 0<|x-x0|<δ 时恒有 |f(x)-A|<ε

    ∀ε>0, ∃δ>0, 0<|x-x0|<δ ⇒ |f(x)-A|<ε
    定义极限
  2. 示例⏱ 50秒🟡

    例如 f(x)=2x，当 x→1，极限为 2。若要 |2x-2|<ε，只需 |x-1|<ε/2，于是 δ 可取 ε/2。

    💬 请学生独立写出 δ 的取值。

    📘 δ 的确定

    从 |f(x)-A| 反推出 |x-x0| 的上界即为 δ

    δ = ε/2
    例子ε-δ
  3. 互动⏱ 30秒🟡

    请对比数列定义：数列中的 N 在这里换成了 δ，它不再是‘项数’，而是‘距离范围’的半径。

    💬 请同桌互相复述：ε 和 δ 各代表什么？

    📘 ε 与 δ

    ε 控制函数值误差，δ 控制自变量距离

    对比理解
  4. 小结⏱ 25秒🟡

    所以 ε 控制输出的精度，δ 控制输入的幅度，二者共同刻画‘无限接近’。

    💬 总结一句话：ε-δ 定义的核心是什么？

    📘 精确化极限

    用 ε 和 δ 的动态控制把‘接近’变成可验证的数学条件

    总结

  • 连续需满足：有定义、极限存在、极限值等于函数值
  • 间断点分为可去、跳跃、第二类三种
  • 闭区间连续函数有有界性、最值、介值、零点定理
  • 零点定理是判断方程根是否存在的重要工具

给出函数连续的三条件，分类间断点，并总结闭区间连续函数的四个重要定理。

讲授分段

  1. 导入⏱ 30秒🟡

    函数在某点的极限存在，等价于左极限和右极限都存在且相等。

    💬 什么叫左极限？什么叫右极限？

    📘 左极限与右极限

    x→x0- 时 f(x) 的极限称为左极限， x→x0+ 称右极限

    lim(x→x0-)f(x), lim(x→x0+)f(x)
    概念极限
  2. 示例⏱ 45秒🟡

    例如分段函数 f(x)=x+1(x≥0) 和 x-1(x<0) 在 x=0 处左右极限分别为 -1 和 1，不相等，所以极限不存在。

    💬 请学生口算左右极限并判断极限是否存在。

    📘 极限存在条件

    lim(x→x0)f(x) 存在当且仅当左右极限存在且相等

    lim(x→x0-)f(x)=lim(x→x0+)f(x)
    条件分段函数
  3. 互动⏱ 40秒🟢

    谁来举一个左右极限相等且极限存在的例子？

    💬 例如 f(x)=|x| 在 x=0 处，左右极限都是 0。

    📘 左右极限相等

    例如 |x| 在 0 处的极限存在

    lim(x→0)|x|=0
    例子
  4. 过渡⏱ 20秒🟢

    如果极限为0，我们称它为无穷小；下面看无穷小与无穷大的关系。

    📘 无穷小

    极限为 0 的变量称为无穷小
