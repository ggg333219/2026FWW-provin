### 1.2 主干链路三个明确断点

**断点 A（阻断级）：`questions` 类型冲突**
- `TeachingNode.questions` 定义为 `list[dict]`（字典列表），normalize 写出的却是 `list[str]`（字符串列表）
- 前端 `_slide_quiz` 渲染时 `for q in questions` 对字典迭代，展示结果为 Python 对象字符串
- **影响**：含 quiz 类型节点的课件预览页面会展示异常，但不会完全崩溃

**断点 B（阻断级）：预览持久化接口缺失**
- `GET /api/v1/gen/preview/{gen_id}` 路由不存在
- `vm.save_snapshot()` 写磁盘，但 `PreviewRenderer` 读的是内存 `_gen_tasks`
- 前端生成后刷新页面，预览内容丢失
- **影响**：无法演示"生成→预览→修改→再生成"完整闭环，这是赛题演示的核心场景

**断点 C（阻断级）：MinIO 导出链路静默失败**
- `job.minio_path` 被赋值为本地路径字符串而非 `minio://` URL
- 前端拿到的下载地址指向 `/download/xxx.pptx`（FastAPI StaticFiles），但若进程重启文件丢失
- **影响**：导出示意图在演示场景下不稳定，容易中断

#### M2-1（必须完成）：实现后端预览持久化接口

**问题**：`GET /api/v1/gen/preview/{gen_id}` 路由不存在，前端刷新后预览内容丢失，无法演示迭代修改闭环。

**操作步骤**：

在 `ai_engine/main.py` 新增以下路由（在 `gen_status` 路由附近添加）：

```python
@app.get("/api/v1/gen/preview/{gen_id}")
async def get_preview(gen_id: str, version: Optional[int] = None):
    """
    GET /api/v1/gen/preview/{gen_id} — 读取版本快照并渲染预览 HTML。

    对应 Go 端：GenerationHandler.Preview → AIEngine.GetPreview
    version: 留空加载最新版；指定版本号加载对应快照。
    前端刷新页面时调用此接口恢复预览内容。
    """
    # 步骤1：优先从内存 dict 读取（最新生成任务）
    async with _gen_tasks_lock:
        task = _gen_tasks.get(gen_id)

    if task:
        nodes = task.nodes if hasattr(task, 'nodes') else []
        version_no = None
    else:
        # 步骤2：内存没有则从 Redis 或磁盘恢复
        redis_data = await _task_store.load_task(gen_id)
        if redis_data:
            task = _restore_task_from_dict(redis_data)
            nodes = task.nodes if task and hasattr(task, 'nodes') else []
        else:
            # 步骤3：从版本快照文件读取（指定版本或最新版）
            vm = get_version_manager()
            snap = vm.load_version(gen_id, version)
            if not snap:
                raise HTTPException(status_code=404, detail="版本不存在")
            nodes = [n.model_dump(mode='json') if hasattr(n, 'model_dump') else n
                     for n in snap.nodes_snapshot]
            version_no = snap.version_number

    if not nodes:
        raise HTTPException(status_code=404, detail="该版本无节点数据")

    renderer = PreviewRenderer()
    html = renderer.render(nodes, course_name=gen_id)

    return {
        "html": html,
        "node_count": len(nodes),
        "version": version_no or (task.generation_id if task else None),
    }
```
