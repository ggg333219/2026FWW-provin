# 采用自然语言驱动的 PPT 元素级修改

课件生成后的局部修改采用“自然语言定位 + 稳定元素 ID + 元素组 + 原子版本事务”的模型，而不是只修改教学节点或把页面重新渲染成图片。教师可以用页码、元素类型、位置和内容描述目标；系统在无法唯一定位时返回候选并等待确认。每次成功修改同时保存修改前后完整快照，生成新的正式版本，保留 PPTX 的原生可编辑对象。这样可以支持连续对话、撤销、回滚、差异追踪和可验证导出，但需要额外维护元素映射、媒体资源确认和 PPTX 元素级验收。

## Considered Options

- 只修改页面/教学节点：实现简单，但无法满足元素级定位和导出验收。
- 将每页栅格化为图片：视觉修改容易，但失去 PPT 可编辑性，拒绝采用。
- 直接让大模型修改 PPTX XML：元素定位和安全性不可控，拒绝作为首期主路径。

## Consequences

- 生成结果需要包含稳定的页面和元素身份，而不只是节点文本。
- 修改、预览、版本和导出必须共享同一份元素快照。
- 图片、图表和批量修改需要风险确认；任一元素失败时整次事务回滚。
- 需要增加浏览器到导出文件的端到端验收，而不能只依赖 Store、Go 或 Python 单元测试。
