# WPS 兼容性验证报告

## 测试环境

- WPS 版本：12.1.0.28505（WPS Office，wpp.exe）
- 操作系统：Windows 11 Home China 10.0.26200

## 验证方法

1. 由 `PPTExporter` 导出测试文件：`data/exports/wps_test.pptx`（3 页：封面 / 内容 / 小结，含 segments 分段数据）
2. 使用 WPS 打开该文件，逐页核对：
   - **人工确认**：2026-08-27，成员实际打开 WPS 复核，确认 **3 页全部正常显示**（封面深蓝底 + 白色标题，内容页、小结页文字齐全）。
   - **WPS COM 渲染核验**（`KWPP.Application`，WPS 官方自动化接口）：
     - `Slides.Count = 3`，与生成数据一致；
     - 每页用 WPS 渲染引擎导出 PNG（cover.png / content.png / summary.png），逐页像素校验均含真实内容：
       - 封面：深蓝色背景 `#245B78` + 左侧橙色竖条 + 白色标题文字；
       - 内容页 / 小结页：浅色背景 `#F5F8FA` + 正文文字。
3. 程序化校验：
   - WPS 进程正常打开文件（无崩溃、无打开失败）
   - PPTX 内文本完整性校验通过（封面测试 / 内容页 / 要点一~三 / 第一段讲授文本 / 小结 / 总结一~二 全部存在，无乱码）

> 说明：`cover.png` 曾有一次为 WPS 打开瞬间的白屏截图（加载未完成即截屏），已用 WPS 渲染引擎重新导出替换；人工打开 WPS 复核时未见此问题。
