## 3. 两种游戏模式功能点

### 3.1 quiz → 「答题挑战」
- 逐题作答，进度条 + 「第 x / N 题」+ 当前实时得分；
- 选项点击后锁定：正确项绿色高亮 + pop 动画，错选项红色 + shake 抖动动画，其余选项降透明度；
- 即时文字反馈（回答正确 / 正确答案是 X）+ 显示解析；
- 答完显示总分（x / N）、正确率百分比、评价语（优秀/良好/继续加油），可一键重新开始。

### 3.2 flashcard → 「知识翻卡」
- CSS 3D flip（`transform: rotateY(180deg)` + `backface-visibility`），点击卡片正反面翻转；
- 上一张 / 下一张导航 + 「x / N」计数器，首尾自动禁用；
- 「我记住了 / 再看看」标记，顶部实时统计已掌握/待巩固数量；
- 全部过完后显示汇总页：掌握数、待巩固卡清单（词头串联），可重新复习。

### 3.3 通用
- 混合素材自动显示「答题挑战 / 知识翻卡」双 tab，单素材只显示对应模式；
- 移动端可用：`viewport` meta 自适应 + 触摸操作 + 窄屏字号降级；
- 教学风格：深蓝标题（#16305e / #1e4a8f）+ 微软雅黑，与 PPT/DOC 导出配色一致；
- 单文件自包含：无任何 `http(s)` 外链、无 `<script src>`/`<img src>` 资源引用；所有文本 `html.escape` 转义，JSON 数据 `</` 转义防 `</script>` 逃逸；
- 空素材渲染友好占位页，不抛异常。

## 4. 导出接入方式（main.py 最小侵入，5 处）

`ExportFormat` 枚举已有 `INTERACTIVE = "interactive"`（`ai_engine/core/schema.py:123`），无需改 schema：

1. S4 导出段新增 `from ai_engine.gen.export_html5 import export_interactive_html`；
2. `_run_export` 新增分支：`fmt in (BOTH, INTERACTIVE)` 时调用 `export_interactive_html(nodes, course_name, output_dir=export_dir, file_name=f"{job_id}.html")`，路径写入 `job.metadata["html_path"]`；
3. MinIO 上传循环扩展为 `(("ppt_path","pptx"), ("doc_path","docx"), ("html_path","html"))`，上传失败降级为本地路径（沿用既有契约）；
4. `GET /api/v1/export/status/{job_id}` 的 download_url 支持 `/download/{job_id}.html`；
5. `GET /download/{job_id}.{extension}` 增加 `html → html_path` 映射，media type `text/html; charset=utf-8`。

**素材来源离线化**：`extract_interactive_items(nodes)` 纯规则抽取、不调 LLM——
- 节点内嵌 `interactive_items` / `metadata.interactive`（build_all 产物）直接使用；
- dict 形态题目（question/options/answer/explanation）归一化为 quiz，answer 兼容「A」字母 / 整数下标 / 选项全文三种形态；
- `segments[].knowledge_card` → 闪卡；
- 纯文本题（`questions` 中的字符串）→ 转为闪卡（正面=问题、背面=节点摘要），**不编造答案**。
