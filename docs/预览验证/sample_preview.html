冒泡排序的基本思想

  • 相邻元素两两比较
  • 每轮把最大值冒泡到末尾
  • 时间复杂度 O(n²)

冒泡排序通过相邻元素两两比较，把较大元素逐步交换到序列尾部。

讲授文本

同学们好，这一页我们先来看冒泡排序的核心思想。请大家注意每一轮比较结束后，最大的元素会像气泡一样浮到序列末尾。

讲授分段

  1. 导入⏱ 30秒🟢

    我们先从一个生活中的例子说起。

  2. 讲解⏱ 60秒🟡

    冒泡排序每一轮都会把当前未排序部分的最大值放到最后。

  3. 示例⏱ 45秒🟢

    比如数组 [5, 3, 8]，第一轮比较后 8 会被放到最后。

  4. 小结⏱ 20秒🟢

    这一段就是本页的小结。
