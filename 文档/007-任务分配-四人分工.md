## 二、任务明细

### A —— Go 后端（5 项）

#### A1. 新增课件项目接口（P0，R3/R4）★最高优先
- **目标**：中间页"我的课件"有真实数据来源，替代平台课程 mock。
- **交付**：
  - 新表 `courseware_projects`（字段见契约 §3.8.3）
  - 接口：`POST /api/v1/coursewares`、`GET /api/v1/coursewares`、`GET /api/v1/coursewares/:project_id/context`
  - 归属人过滤（owner_id），按 updated_at 倒序
- **验证**：`curl -X POST /api/v1/coursewares` 建项目 → `GET` 列表能查到 → 重启后仍在（Postgres 持久化）
- **依赖**：无（可立即开工）

#### A2. 草稿自动保存与读取接口（P0，R10）
- **目标**：编辑内容后端落库，不依赖 localStorage 单点。
- **交付**：
  - `PUT /api/v1/coursewares/:project_id/draft`、`GET /api/v1/coursewares/:project_id/draft`
  - `draft_json`（jsonb）存意图/大纲/证据引用/节点快照
- **验证**：PUT 草稿 → 重启服务 → GET 读回内容一致
- **依赖**：A1（表结构）

#### A3. 当前步骤持久化（P0，R2）
- **目标**：刷新/重进后能回到上次所在步骤。
- **交付**：`PUT /api/v1/coursewares/:project_id/step`，值域 `s1_intent/s2_material/s3_studio/s4_version`
- **验证**：PUT step=s3_studio → GET context 返回该 step
- **依赖**：A1

#### A4. gen/create 关联 project_id（P0，R4）
- **目标**：生成任务与课件项目绑定，供"继续编辑"读取版本链。
- **交付**：`POST /api/v1/gen/create` 增加 `project_id` 入参，成功回填 `courseware_projects.gen_id`
- **验证**：传 project_id 生成成功 → 查 courseware_projects.gen_id 已回填
- **依赖**：A1
- **注意**：字段只增不删，保持现有调用兼容

#### A5. 导出接口带版本号（P2，R11）
- **目标**：导出明确显示"课件名称 v3"，解决"字母乱码无法确认导出对象"。
- **交付**：export 响应体增加 `courseware_title` + `version`；文件名规范化为 `{标题}_v{N}.{ext}`
- **验证**：导出 → 响应含版本号、文件名可读
- **依赖**：无（可并行）

### B —— Python AI Engine（4 项）

#### B1. 大纲生成质量优化（P0，R1 相关）
- **目标**：解决"只有输入'重点是...'才切块"的笨拙表现，提升知识点切分与概要生成质量。
  （注：大纲编辑器的节点渲染/sessionId 缺陷已由本轮修复提交 `4354d1f` 解决，B 聚焦生成质量本身）
- **交付**：优化 LLM prompt 与 `schema.py` 的节点切分逻辑，支持自然语言表述（非固定句式）
- **验证**：输入不含"重点是"的语句 → 仍能正确切出知识点；同一输入多次生成结构稳定
- **依赖**：无

#### B2. 局部 RAG 检索接口（P1，R6/R7）
- **目标**：S3 工作台内可检索、可按范围（当前节点/当前页/整课）应用证据。
- **交付**：检索接口支持 `scope` 参数与 `node_id`/`page_id` 过滤，返回切片+来源
- **验证**：指定 scope=node 检索 → 只返回该节点相关切片
- **依赖**：无（A/C 后续对接）

#### B3. 互动小游戏生成（P1，文档 S3 清单项）
- **目标**：interactive 类型节点能真正产出可玩的互动内容（当前"互动小游戏无法生成"）。
- **交付**：`/gen/content` 对 `node_type=interactive` 产出 HTML5 可运行内容
- **验证**：interactive 节点生成 → 返回可渲染的 HTML，浏览器能打开运行
- **依赖**：无

#### B4. HTML5 预览/导出去 mock（P1，文档 S4 清单项）
- **目标**：解决"html课件预览接口接的是旧的""html5导出是mock数据"。
- **交付**：预览与导出走真实生成结果，移除 mock 分支
- **验证**：导出产物内容与预览一致、非占位数据
- **依赖**：B3（互动内容部分）

### C —— Vue 前端（5 项）

#### C1. 中间页改造为"我的课件"（P0，R3/R4/R12）★最高优先
- **目标**：中间页显示本人真实课件列表，删除平台课程与 mock。
- **交付**：
  - `MiddlePage.vue` 主区改为课件卡片列表（名称/最近编辑/版本/状态/步骤）
  - 空状态："还没有课件，开始创建第一份课件"
  - 移除"平台管理"入口与 `PlatformManagementPanel` 引用（对应文档 3.6 清理范围）
  - 卡片操作：继续编辑 / 查看版本 / 导出
- **验证**：新建课件 → 中间页出现该卡片；无课件时显示空状态；平台课程 tile 消失
- **依赖**：A1（接口）——可先用 mock 数据并行开发，接口就绪后切换

#### C2. 继续编辑入口（P0，R2/R3）
- **目标**：点历史课件能恢复到上次步骤与内容。
- **交付**：`/courseware/create?generation_id={id}` 参数解析 + 按 current_step 跳转；入口统一处理，不在各 S 页分散实现
- **验证**：建课件 → 退出 → 中间页点卡片 → 回到 S3 且大纲内容完整
- **依赖**：A2/A3

#### C3. 自动保存草稿 + 保存状态提示（P0，R10）
- **目标**：编辑自动保存，与"保存新版本"明确区分。
- **交付**：节流自动保存（编辑停 1-3s / 切层 / 离开页面）；状态提示文案（正在保存… / 已保存草稿 · 时间 / 保存失败·点击重试 / 有未保存变更）；"保存草稿"与"保存新版本"双按钮
- **验证**：编辑后 3s 内出现"已保存草稿"；刷新后内容仍在
- **依赖**：A2

#### C4. PPT 样式层（P1，R8）
- **目标**：新增样式调整层，且样式改动不触发 RAG、不改事实内容。
- **交付**：S3 增加"PPT 样式"层（页面预览 + 样式 AI 对话 + 全局模板/配色/字体）；样式调整只改呈现
- **验证**：调样式后内容与引用关系不变、不发起检索请求
- **依赖**：无（可独立开发）

#### C5. 数据丢失提示与导出显示版本（P2，R13/R11）
- **目标**：缓存被清时给明确提示；导出显示版本号。
- **交付**：本地数据缺失提示"未找到本地编辑数据，是否重新开始？"；S4 导出界面显示"课件名称 v3"
- **验证**：清 localStorage 后进入 → 出现提示；导出界面显示版本号
- **依赖**：A5

## 三、接口契约（冻结口径，A/B/C 共同遵守）

统一响应：`{ ok, data, error }`，前缀 `/api/v1`，字段只增不删。

| 方法 | 路径 | 说明 | 负责 |
|---|---|---|---|
| POST | `/api/v1/coursewares` | 新建课件项目 | A |
| GET | `/api/v1/coursewares` | 我的课件列表 | A |
| GET | `/api/v1/coursewares/:project_id/context` | 恢复整课上下文 | A |
| PUT | `/api/v1/coursewares/:project_id/step` | 持久化当前步骤 | A |
| PUT | `/api/v1/coursewares/:project_id/draft` | 自动保存草稿 | A |
| GET | `/api/v1/coursewares/:project_id/draft` | 读取最新草稿 | A |

**数据表 `courseware_projects`**：`project_id`(PK) / `owner_id` / `title` / `current_step` / `gen_id`(nullable) / `status` / `draft_json`(jsonb) / `created_at` / `updated_at`
