# 赛题核心流程缺口

## 背景

本届服务外包省赛 A12 赛题的核心场景是：

> **教师提出修改需求 → 系统理解需求 → 生成新 PPT（版本）**

即：教师在 S3/S4 看到生成的课件后，针对具体页面提出修改指令（"这里加一个游戏设计"、"把第三页标题改一下"），系统理解后生成新的 PPT 版本。

## 完整流程图（目标状态）

```
教师上传资料（S2）
        ↓
    S1 意图理解
        ↓
    S3 生成初版 PPT  ←── gen/create 流水线（缺失触发入口）
        ↓ 产生 gen_id
    S4 版本管理（此时有数据可用）
        ↓ 教师提出修改需求
    系统理解 NL 修改指令（缺失）
        ↓
    gen/modify 应用命令
        ↓
    save_snapshot 保存新版本
        ↓
    新 PPT 生成完成（S4 版本历史出现新版本）
        ↓
    教师预览/导出
```

## 三个断点

| 断点 | 位置 | 现状 | 修复优先级 |
|------|------|------|-----------|
| A | S3 生成入口 | "AI 生成脚本"走 ai-generate，不产生 gen_id | **P0** |
| B | S4 NL 理解 | 自然语言指令无法被解析为结构化命令 | **P0** |
| C | S3 预览联动 | 修改后无法在 S3 实时预览新 PPT | P2 |

**断点 A + B = 核心流程完全不通**。

## 断点 A：S3 无法触发完整生成

详见 [004-S3生成链路问题.md](004-S3生成链路问题.md)。

**现状**：S3StudioPage 没有"生成完整课件"按钮，无法调用 gen/create。

**需要**：新增按钮 → 调用 gen/create → 流水线完成 → gen_id 写入 localStorage → S4 有数据可用。

## 断点 B：S4 自然语言无法理解

详见 [005-S4修改指令问题.md](005-S4修改指令问题.md)。

**现状**：CommandParser 正则能力极弱，老师无法用自然语言提修改需求。

**需要**：增加 LLM 路由层，或前端在提交前调用 LLM 将 NL 转换为结构化命令。

## 断点 C：修改后无法实时预览（新 PPT）

**现状**：gen/modify 生成新版本后，S3 预览区的 PPT 不会自动更新。老师需要刷新页面或手动切换版本。

**影响**：用户体验割裂，看不到修改效果。

**修复方案（P2）**：在 S4 提交修改成功后，通过 WebSocket 或 localStorage 通知 S3 刷新预览区。

## 实施顺序建议

```
Step 1：修复断点 A
  └→ S3StudioPage 新增"生成完整课件"按钮
  └→ generationStore.createFullCourseGeneration
  └→ 验证：S4 版本历史有 v1

Step 2：修复断点 B
  └→ 在 gen/modify 前增加 LLM NL→命令转换
  └→ 或前端新增自然语言输入框
  └→ 验证：输入"在导入部分加一个互动游戏"，版本历史出现 v2

Step 3（可选）：修复断点 C
  └→ S4 提交成功后通知 S3 刷新预览
```

## 验收标准（完整赛题流程）

- [ ] S3 点击"生成完整课件"，流水线完成后 S4 可查看版本历史 v1
- [ ] S4 输入"这里加一个游戏设计"，提交后版本历史出现 v2
- [ ] S4 版本历史中可看到 v1、v2 两个版本，且内容不同
- [ ] 刷新页面后 gen_id 不丢失，S4 仍能正常加载版本历史
- [ ] 浏览器控制台无红色报错
