# S3 生成链路问题

## 问题 1：S3StudioPage 无法生成完整课件（P0）

### 现象

S3StudioPage 有两个按钮：

1. **"AI 生成脚本"**（当前)：调用 `POST /api/v1/teacher/coursewares/:id/scripts/ai-generate`
   - 只生成单页讲稿（script 文本）
   - 写 DB：更新 `teaching_nodes.script_text` 和 `course_pages.script_text`
   - ✅ 速度快，秒级完成
   - ❌ **不产生 gen_id，不保存版本快照，S4 无数据可用**

2. **"生成完整课件"**（缺失)：应调用 `POST /api/v1/gen/create`
   - 触发完整流水线：outline → nodes → 逐节点生成讲稿
   - ✅ 产生 gen_id（`course_{uuid12}`）
   - ✅ 保存版本快照 v_1.json
   - ✅ S4 版本管理有数据可用
   - ❌ 异步，需轮询状态

### 根因

前端没有实现调用 `gen/create` 流水线的入口，S3StudioPage 只有一个 `handleGenerateAIScript` 函数走 `ai-generate` 路径。

`gen/create` 是完整的 outline → nodes → 逐节点生成流水线，设计目标是生成整课大纲和节点树，保存版本快照供 S4 管理。`ai-generate` 是轻量的单页讲稿生成，仅写 DB，不介入版本体系。

### 影响

赛题流程"S1→S2→S3→S4"走到 S4 时，版本历史为空，无法演示版本管理功能。

---

## 修复方案（实施步骤）

在 `S3StudioPage.vue` 新增"生成完整课件"按钮（与"AI 生成脚本"并存），调用 `gen/create` 完整流水线。

### 涉及文件

| 文件 | 改动 |
|------|------|
| `frontend/teacher/src/stores/generationStore.js` | 新增 `createFullCourseGeneration` action，调用 `generationApi.createGeneration`，从响应提取 gen_id 写入 `lastGenId` |
| `frontend/teacher/src/services/v1/generationApi.js` | 确认 `createGeneration` 方法存在 |
| `frontend/teacher/src/pages/S3StudioPage.vue` | 新增"生成完整课件"按钮 + `handleGenerateFullCourse` handler |

### Step 1：`generationStore.js` 新增 action

在 `actions` 部分新增：

```javascript
/**
 * 创建完整课件生成任务（gen/create 流水线）。
 * 流水线异步执行，调用方应通过 waitForCoursewareGeneration 轮询状态。
 * 成功后 gen_id 自动写入 lastGenId + localStorage。
 */
async createFullCourseGeneration(request) {
  const response = await teacherV1Api.generation.createGeneration(request)
  const task = response?.data || response || {}
  const generationId = task.generation_id || task.gen_id || task.genId || ''
  if (generationId) this.setLastGenId(generationId)
  return task
},
```

同时确认 `waitForCoursewareGeneration` 支持 `onProgress` 回调（扩展方式）：

```javascript
async waitForCoursewareGeneration(taskId, { intervalMs = 500, maxAttempts = 240, onProgress = null } = {}) {
  for (let attempt = 0; attempt < maxAttempts; attempt += 1) {
    const status = await this.getCoursewareGenerationStatus(taskId)
    const progress = Number(status.progress_pct ?? (Number(status.progress || 0) * 100))
    if (onProgress) {
      onProgress(
        Number.isFinite(progress) ? progress : 0,
        status.stage_text || '正在生成课件'
      )
    } else {
      this.setGenerateProgress(
        Number.isFinite(progress) ? progress : 0,
        status.stage_text || '正在生成课件'
      )
    }
    if (status.status === 'done' || status.status === 'completed') return status
    if (status.status === 'failed' || status.status === 'error') {
      throw new Error('生成失败：' + (status.error || status.message || '未知错误'))
    }
    await new Promise(r => setTimeout(r, intervalMs))
  }
  throw new Error('生成超时，请稍后刷新页面重试')
},
```

新增 handler：

```javascript
async function handleGenerateFullCourse() {
  if (!courseId.value) return
  generationStore.setGenerating(true)
  generationStore.setGenerateProgress(0, '正在创建生成任务...')

  try {
    // 尝试从 localStorage 读取证据包（S2 证据透传）
    let evidence = null
    try {
      const raw = window.localStorage.getItem('fuww_s2_evidence_packet')
      if (raw) evidence = JSON.parse(raw)
    } catch (e) { /* ignore */ }

    const intent = {
      topic: courseName.value || `课件 ${courseId.value}`,
      subject: '',
      learningObjectives: [],
      gradeLevel: '',
      outputFormat: ['ppt'],
    }

    const task = await generationStore.createFullCourseGeneration({
      course_id: courseId.value,
      title: courseName.value || `课件 ${courseId.value}`,
      intent,
      evidence_packet: evidence,
      template_id: '',
    })

    if (!task.task_id) throw new Error('生成服务未返回 task_id')

    // 轮询等待流水线完成
    await generationStore.waitForCoursewareGeneration(task.task_id, {
      onProgress: (pct, stage) => {
        generationStore.setGenerateProgress(pct, stage)
      }
    })

    generationStore.setGenerateProgress(100, '生成完成')
    alert(`✅ 完整课件已生成！\ngen_id: ${generationStore.lastGenId}\n请前往 S4 版本管理查看。`)
  } catch (err) {
    console.warn('生成失败', err)
    alert('生成失败：' + (err.message || '未知错误'))
  } finally {
    generationStore.setGenerating(false)
  }
}
```

## gen/create 请求/响应契约

**请求**：

```json
POST /api/v1/gen/create
{
  "course_id": "3be64dfe-5ef7-4a6b-a0c7-0635fd69d6d4",
  "title": "Node服务器和常见模块",
  "intent": {
    "topic": "Node服务器和常见模块",
    "output_format": ["ppt"]
  },
  "evidence_packet": null
}
```

**响应**：

```json
{
  "code": 200,
  "data": {
    "task_id": "gen_b7bd77dee6d4",
    "generation_id": "course_d5a84456e0e7",
    "status": "pending"
  }
}
```

轮询 `GET /api/v1/gen/status/{task_id}` 至 `status: done`，AI 引擎自动保存 v_1 快照至 `data/versions/{gen_id}/`。

## 验收步骤

1. S3StudioPage 加载课件后，点击"**生成完整课件**"（新按钮）
2. 等待流水线完成（进度条 0→100%），出现"✅ 生成完成"提示
3. 出现弹窗显示 gen_id（如 `course_d5a84456e0e7`）
4. 打开 DevTools → Application → Local Storage，确认 `fuww_last_gen_id` 已写入
5. 切到 S4 版本管理，gen_id 已自动填入
6. 点击"加载版本"，版本历史显示 v1

## 问题 2：gen_id 与 course_id 是两套独立体系

### 现象

`gen/create` 返回的 gen_id（`course_{uuid12}`）与 PostgreSQL 的 course_id（`3be64dfe-...`）没有任何关联。

### 影响

同一个 course_id 多次调用 gen/create 会产生多个 gen_id（多个版本分支），无法自动关联到同一个课件。

### 临时方案

用户在 S4 手动管理 gen_id，或前端在调用 gen/create 后维护 `{courseId → genId}` 的映射（待实现）。

## 问题 3：gen/create 流水线无前端进度回调

`waitForCoursewareGeneration` 目前不支持 `onProgress` 回调，进度条无法实时更新。

**修复**：扩展 `waitForCoursewareGeneration` 支持 `onProgress(pct, stageText)` callback。
