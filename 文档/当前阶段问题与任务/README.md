## 术语对照

| 术语 | 说明 |
|------|------|
| `gen_id` | AI 引擎内部版本体系 ID，格式 `course_{uuid12}`，S4 版本管理使用 |
| `course_id` | PostgreSQL 课件记录 ID，S3 讲稿编辑使用 |
| `ai-generate` | 单页讲稿生成端点，写 DB，不产生 gen_id |
| `gen/create` | 完整流水线端点，outline→nodes→逐节点生成，保存版本快照 |
| `gen/modify` | S4 修改指令端点，应用编辑命令到节点树 |
