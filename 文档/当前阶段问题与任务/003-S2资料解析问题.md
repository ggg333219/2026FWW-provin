# S2 资料解析问题

## 问题：图片信息无法提取

### 现象

上传 PPT/PDF 文件后，文字内容可以正常解析，但图片中的公式、图表、数据结论无法被理解。S2 知识库检索时，图片内容作为独立 Chunk 的信息丢失。

### 根因

环境变量 `AI_USE_VISION` 默认设为 `"false"`：

```python
# ai_engine/parser.py:114
use_vision = os.getenv("AI_USE_VISION", "false").strip().lower() == "true"
```

当 `use_vision=false` 时：
- PPTX 图片：`_extract_pptx_images` 提取了 base64，但没有调用 `_describe_images` 做 LLM 视觉理解
- PDF 图片：完全不处理，PDF 页面转图片描述被跳过

### 代码路径分析

```python
# parser.py:50-86  _describe_images
def _describe_images(self, images: list[dict], slide_index: int) -> str:
    use_vision = os.getenv("AI_USE_VISION", "false").strip().lower() == "true"
    # ...
    if use_vision and images:
        for img_idx, img in enumerate(images):
            # 调用 LLM vision API 描述图片
            descriptions.append(f"[图片{img_idx+1}]: {desc.strip()}")
    else:
        descriptions.append(f"[图片{img_idx+1}]: (未启用视觉理解)")
    # ...
```

```python
# parser.py:147-167  parse_pptx
use_vision = os.getenv("AI_USE_VISION", "false").strip().lower() == "true"
images = self._extract_pptx_images(slide) if use_vision else []  # ← 直接跳過
if has_text or (has_images and use_vision):
    if use_vision and images:
        vis_desc = self._describe_images(images, slide_index)  # ← 永远不会执行
```

### 修复方案

**快方案**：修改 `ai_engine/parser.py` 中 `AI_USE_VISION` 的默认值：

```python
# parser.py:114
use_vision = os.getenv("AI_USE_VISION", "true").strip().lower() == "true"
```

**影响**：每次解析含图片的 PPTX/PDF 都会额外调用 LLM vision API，成本略有增加，但图片信息可正确提取。

**注意**：需要确认 `AI_USE_VISION=true` 时 LLM API key 配置正确，否则图片描述会失败并降级。

### 涉及文件

- `ai_engine/parser.py`（`_describe_images`、`parse_pptx`、`parse_pdf` 中 `use_vision` 默认值）

### 验收步骤

1. 上传一个含图片的 PPTX（如课件截图、公式截图）
2. 启用 `AI_USE_VISION=true` 重新解析
3. 检查返回的 chunks 中图片对应条目的 content 字段是否包含 `[图片1]: ...` 的 LLM 描述
4. 检索该图片相关关键词，确认能命中
