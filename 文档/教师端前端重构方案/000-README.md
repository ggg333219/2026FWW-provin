# 教师端前端重构方案

这是一份面向 4 人团队协作的教师端前端重构整合文档。

目标是把现有 `App.vue` 驱动的单页/Tab 结构，重构为可路由、可分工、可联调、可验收的教学工作台。

## 核心原则

1. 先定底座，再拆模块。
2. 路由、Store、API 契约先冻结。
3. AppShell 先抽离，避免多人同时改 `App.vue`。
4. S1-S4 分区并行开发，最后串流程和验收。

## 适用范围

- 教师前端工作台
- Vue Router + Pinia 重构
- S1-S4 skill 页面化落地
- 学情分析与版本导出闭环
