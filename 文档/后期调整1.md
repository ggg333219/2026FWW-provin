2. 系统架构关键事实
本方案基于以下代码事实，修改前需确认：
- PPT 导出是 SVG 架构：export_ppt.py 由 page_spec 驱动，与预览侧 svg_renderer 共享同一份 build_page_spec（export_ppt.py:383、:964），不是单点坐标硬编码。
- 三层超时链：前端请求 45s < Go ai.timeout 30s < 引擎 LLM 120s×2（重试 1 次，退避 2s/4s）——Go 会在 LLM 第二次重试前超时。
- S1 静默降级：intent/service.py:170-207 的 _extract_summary，LLM 结果验证失败后被 except Exception: pass 吞掉，静默回退规则引擎，无日志。
- Go 后端已有 outline PUT 接口：teacher.go:211 PUT /api/v1/outlines/:outline_id，H4 只需前端接线。
- 草稿 key 已有分区：coursewareDraft.js:13 的 resumeDraftKey(projectId) 已按项目分区，但部分组件仍用全局 key。

6. 瑞士教育风专项分析
当前 UI 选择「瑞士教育风」后，实际生效的只有调色板（克莱因蓝 #315fd4，注意 SKILL.md 定义的是 #002FA7，两边数值不一致本身是一处断点）。SKILL.md 定义的设计语言（直角、16列网格、1px细线、字号极端反差、Inter Tight/JetBrains Mono、26种布局池）在 PPTX 导出中均未落地。
关键架构事实：当前 PPT 导出是 SVG 架构——page_spec 驱动 svg_renderer（预览）和 export_ppt.py（导出 PPTX）共享同一份规格，不是单点坐标硬编码。瑞士风改造必须在三处联动，不能只改 export_ppt。
