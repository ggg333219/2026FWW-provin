## 1. S1 意图理解接口

### 1.1 意图提取

```
POST /api/v1/intent/extract
```

**请求**：
```json
{
  "session_id": "conv_xxx",
  "messages": [
    { "role": "teacher", "content": "帮我做一份45分钟的排序算法课件", "timestamp": "..." },
    { "role": "assistant", "content": "请问面向哪个年级？", "timestamp": "..." },
    { "role": "teacher", "content": "大一计算机专业", "timestamp": "..." }
  ]
}
```

**响应**：
```json
{
  "intent": {
    "topic": "排序算法",
    "duration_minutes": 45,
    "style": "简洁",
    "target_student": "大一计算机专业",
    "knowledge_points": ["冒泡排序", "快速排序", "归并排序", "时间复杂度"],
    "output_format": ["ppt"],
    "with_interactive": true,
    "key_difficulties": ["递归理解", "复杂度分析"],
    "expected_outcomes": ["理解各排序算法原理", "能分析时间复杂度"]
  },
  "missing_fields": [],
  "session_status": "confirmed"
}
```

### 1.2 意图确认

```
POST /api/v1/intent/confirm
```

**请求**：
```json
{
  "session_id": "conv_xxx",
  "intent": { /* 确认后的完整意图 */ }
}
```

**响应**：
```json
{
  "status": "confirmed",
  "intent_id": "intent_xxx"
}
```

## 2. S2 多模态交互接口

### 2.1 上传解析

```
POST /api/v1/parse/process
```

**请求**（multipart/form-data）：
```
file: <二进制文件>
session_id: "conv_xxx"
intent_id: "intent_xxx"
```

**响应**（异步）：
```json
{
  "task_id": "task_xxx",
  "status": "processing"
}
```

### 2.2 查询解析状态

```
GET /api/v1/parse/status/:task_id
```

**响应**：
```json
{
  "status": "done",
  "result": {
    "parsed_chunks": [
      {
        "chunk_id": "chunk_001",
        "type": "text",
        "content": "排序算法是计算机科学中最基础的算法之一...",
        "page_ref": 3,
        "source_file": "教材第三章.pdf"
      }
    ],
    "errors": []
  }
}
```

### 2.3 视频解析

```
POST /api/v1/parse/video
```

**请求**（multipart/form-data）：
```
file: <视频文件>
```

**响应**：
```json
{
  "task_id": "task_xxx",
  "status": "processing"
}
```

## 3. KB 知识库接口

### 3.1 知识检索

```
POST /api/v1/rag/search
```

**请求**：
```json
{
  "query": "快速排序的实现原理",
  "knowledge_base_ids": ["kb_xxx"],
  "top_k": 5,
  "min_score": 0.6
}
```

**响应**：
```json
{
  "results": [
    {
      "chunk_id": "chunk_001",
      "content": "快速排序通过选取一个基准元素...",
      "score": 0.92,
      "source": {
        "file_name": "教材第三章.pdf",
        "page": 15
      }
    }
  ],
  "total_chunks": 150
}
```

### 3.2 证据融合

```
POST /api/v1/rag/evidence
```

**请求**：
```json
{
  "query": "生成一份排序算法课件",
  "context": {
    "intent": { /* 结构化意图 */ },
    "current_nodes": []
  },
  "knowledge_base_ids": ["kb_xxx"]
}
```

**响应**：
```json
{
  "evidence_packet": {
    "relevant_chunks": [
      {
        "chunk_id": "chunk_001",
        "content": "...",
        "score": 0.92
      }
    ],
    "synthesized_context": "根据教材内容，排序算法部分主要涵盖...",
    "citations": [
      {
        "chunk_id": "chunk_001",
        "text_snippet": "快速排序通过选取基准元素...",
        "source_ref": "教材第三章.pdf p.15"
      }
    ]
  }
}
```

### 3.3 文档上传索引

```
POST /api/v1/knowledge/upload
```

**请求**（multipart/form-data）：
```
file: <文档文件>
knowledge_base_id: "kb_xxx"
```

**响应**：
```json
{
  "task_id": "task_xxx",
  "status": "indexing"
}
```

```json
  "status": "generating"
}
```

### 4.2 查询生成状态

```
GET /api/v1/gen/status/:task_id
```

**响应**：
```json
{
  "status": "preview",
  "current_node": "快速排序",
  "progress_pct": 80,
  "result": {
    "generation_id": "gen_xxx",
    "nodes": [

        "node_id": "node_001",
```

```json

  "task_id": "task_xxx",
  "new_version": 4,
```

### 4.5 导出课件

## 6. 通用数据模型

```json
{
  "topic": "string | null",
  "duration_minutes": "integer | null",
  "style": "string | null",
  "target_student": "string | null",
  "knowledge_points": ["string"],
  "output_format": ["ppt", "doc", "both"],
  "with_interactive": "boolean",
  "key_difficulties": ["string"],
  "expected_outcomes": ["string"],
  "missing_fields": ["string"]
```

```json
{
  "node_id": "string",
  "title": "string",
  "type": "slide | section | quiz",

  "page_ref": "integer",

  "examples": ["string"],
```

```json

  "relevant_chunks": [

    {
      "chunk_id": "string",
```

```json
{
```

## 7. 状态机汇总

### 7.1 会话状态机

```
collecting → clarifying → confirming → confirmed → locked
     ↑           ↑                          ↓
     └───────────┴── 教师新消息回到 collecting
```

| 状态 | 含义 |
|------|------|
| `collecting` | 收集信息中，字段不全 |
| `clarifying` | 追问中，部分字段已填 |
| `confirming` | 所有字段齐备，等待教师确认 |
| `confirmed` | 教师已确认意图 |
| `locked` | 生成请求已到达，不再接受修改 |

### 7.2 文件解析状态机

```
UPLOADED → PARSING → CHUNKED → INDEXED → DONE
UPLOADED → PARSING → FAILED
```

### 7.3 生成状态机

```
INTENT_LOCKED → EVIDENCE_GATHERING → STRUCTURING → GENERATING → PREVIEW → MODIFYING → DONE
                                                           ↓
                                                     [REGENERATE]
```

### 7.4 版本生命周期

```
V1(editable) → V2(editable) → ... → Vn(LOCKED)
回滚: 克隆目标版本为新的可编辑版本
```

## 9. Agent ↔ Tool 调用协议

> 适用于 Go 后端的 Agent Orchestrator 调用 AI Engine 各 Tool 时的通用包装。

### 9.1 通用请求体

```json
{
  "tool_name": "parse_document",
  "request_id": "req_xxx",
  "payload": {}
}
```

### 9.2 通用响应体

```json
{
  "ok": true,
  "tool_name": "parse_document",
  "tool_version": "v1",
  "request_id": "req_xxx",
  "data": {},
  "error": ""
}
```

### 9.3 核心 Tool 列表

| Tool 名 | 输入 | 输出 | 所属 Skill |
|---------|------|------|-----------|
| `parse_document` | file_url, file_type | parsed_pages, stats | S2 |
| `parse_video` | file_url | key_frames, transcript, summary | S2 |
| `parse_knowledge` | text | structure[] | KB |
| `reconstruct_document` | parsed_document | chapters, teaching_nodes | S2→S3 |
| `generate_script` | page, content | script, mindmap_markdown | S3 |
| `generate_from_markdown` | markdown | node_tree, scripts | S3 |
| `ask_with_context` | question, context | answer, source, need_reteach | S1 |
| `generate_audio` | course_id, page, nodes | sections, audio_urls | S3（可选） |

### 9.4 接口版本管理

- **字段新增**：只增不删，向后兼容
- **字段废弃**：先标记 `deprecated`，保留至少一个迭代周期
- **变更流程**：提交接口变更说明 → 前后端评审 → 联调环境验证 → 更新本文档
