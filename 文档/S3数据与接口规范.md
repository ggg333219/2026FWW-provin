# S3 数据与接口规范

> S3 课件生成阶段的数据模型、字段命名、状态枚举和 HTTP API 统一规范。
>
> 适用范围：前端 ↔ Go 后端 ↔ Python AI Engine。
>
> 版本：v1.0 · 2026-09-03

---

## 1. 统一约定

### 1.1 传输格式

- 所有接口使用 JSON 请求和 JSON 响应。
- 所有字段使用 `snake_case` 命名。
- 所有 ID 使用字符串类型。
- 时间使用 ISO 8601 格式，例如 `2026-09-03T10:20:00+08:00`。
- 百分比字段使用 `0-100` 的数值，例如 `progress_pct: 45`。
- 请求失败使用 HTTP 状态码表示类别，响应体使用统一错误结构。

### 1.2 ID 命名规则

| ID | 含义 | 作用范围 |
|---|---|---|
| `session_id` | 教师与智能体的会话 ID | S1/S2/S3 全流程 |
| `intent_id` | 已确认教学意图 ID | S1 → S3 |
| `outline_id` | 一份课程大纲 ID | 大纲草稿及其版本 |
| `generation_id` | 一次课件生成任务的结果 ID | 内容生成、页面生成、预览 |
| `version_id` | 一次生成结果的版本 ID | 版本保存、回滚、导出 |
| `page_id` | 生成结果中的页面 ID | 单页查询、生成、修改 |
| `node_id` | 大纲节点与内容节点的稳定 ID | 大纲、内容、页面之间的关联 |
| `interactive_asset_id` | 互动资源 ID | HTML5/GIF/MP4 资源关联 |
| `task_id` | 异步后台任务 ID | 状态轮询 |

关系必须保持如下：

```text
session_id
  → intent_id
  → outline_id + outline_version
  → generation_id
  → version_id
  → page_id + node_id
  → interactive_asset_id
```

`task_id` 是异步执行编号，不替代 `outline_id`、`generation_id` 或 `version_id`。

### 1.3 兼容字段规则

S3 新接口统一使用以下字段：

- `node_id`，不使用 `nodeId`。
- `generation_id`，不使用 `gen_id` 作为请求主字段。
- `estimated_duration_minutes`，单位统一为分钟。
- `key_points` 为字符串数组。
- `questions` 为字符串数组；结构化题目放在 `interactive_items` 中。

现有 `/api/v1/gen/*` 接口继续兼容，但新代码不得新增另一套同义字段。

## 2. 数据模型

### 2.1 大纲节点 `OutlineNode`

大纲节点只描述“准备讲什么”，不包含完整讲稿正文。

```json
{
  "node_id": "node_001",
  "order": 1,
  "title": "冒泡排序原理",
  "summary": "介绍冒泡排序的基本过程",
  "node_type": "content",
  "key_points": [
    "相邻元素比较",
    "元素交换",
    "时间复杂度"
  ],
  "estimated_duration_minutes": 10,
  "source_chunk_ids": [],
  "interactive_plan": null
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `node_id` | string | 是 | 节点稳定 ID，生成后不可随意改变 |
| `order` | integer | 是 | 节点顺序，从 1 开始且不可重复 |
| `title` | string | 是 | 节点标题 |
| `summary` | string | 是 | 节点摘要 |
| `node_type` | string | 是 | `content`、`section`、`quiz`、`interactive`、`summary` |
| `key_points` | string[] | 是 | 核心知识点，可为空数组但字段必须存在 |
| `estimated_duration_minutes` | number | 是 | 预计时长，必须大于 0 |
| `source_chunk_ids` | string[] | 否 | 关联的资料切片 ID |
| `interactive_plan` | object/null | 否 | 互动规划 |

大纲节点禁止新增完整内容字段：`script`、`segments`、`interactive_items`。

### 2.2 互动规划 `InteractivePlan`

互动规划在大纲阶段声明，具体题目在内容生成阶段产生。

```json
{
  "enabled": true,
  "kind": "quiz",
  "duration_minutes": 5,
  "question_count": 3,
  "auto_grading": true,
  "delivery": "html5_link"
}
```

| 字段 | 类型 | 必填 | 可选值/说明 |
|---|---|---:|---|
| `enabled` | boolean | 是 | 是否需要互动 |
| `kind` | string | 是 | `quiz`、`flashcard`、`poll`、`game` |
| `duration_minutes` | number | 是 | 互动预计时长 |
| `question_count` | integer | 否 | 题目数量 |
| `auto_grading` | boolean | 否 | 是否自动判分 |
| `delivery` | string | 是 | `html5_link`、`ppt_native`、`standalone_html` |

### 2.3 大纲 `Outline`

```json
{
  "outline_id": "outline_001",
  "outline_version": 1,
  "session_id": "session_001",
  "intent_id": "intent_001",
  "status": "draft",
  "title": "排序算法",
  "nodes": [],
  "created_at": "2026-09-03T10:00:00+08:00",
  "updated_at": "2026-09-03T10:00:00+08:00",
  "confirmed_at": null
}
```

`status` 只允许：

```text
draft       草稿，可继续生成修改结果
confirmed   已确认，可用于正式内容生成
superseded  已被新版本替代
```

确认后的大纲不得原地覆盖。修改确认大纲时生成新的 `outline_version`，旧版本保留。

### 2.4 内容节点 `ContentNode`

内容节点由确认后的大纲生成，允许包含完整讲稿和互动内容。

```json
{
  "node_id": "node_001",
  "order": 1,
  "title": "冒泡排序原理",
  "summary": "介绍冒泡排序的基本过程",
  "node_type": "content",
  "content": "冒泡排序是一种通过反复比较相邻元素完成排序的算法。",
  "script": "教师可以先从生活中的排队场景引入……",
  "key_points": ["相邻元素比较", "元素交换", "时间复杂度"],
  "segments": [],
  "interactive_items": [],
  "source_chunk_ids": [],
  "citation_refs": []
}
```

内容节点可复用现有 `TeachingNode`，但必须保留所属的 `node_id` 和 `order`。

### 2.5 页面 `GenerationPage`

```json
{
  "page_id": "page_001",
  "generation_id": "generation_001",
  "node_id": "node_001",
  "page_order": 1,
  "status": "done",
  "content_status": "done",
  "render_status": "done",
  "preview_url": "/api/v1/generations/generation_001/pages/page_001/preview",
  "interactive_asset_id": null,
  "error": null
}
```

页面 `status` 只允许：

```text
pending      尚未开始
processing   正在生成

done         生成完成
failed       生成失败，可单页重试
```

`content_status` 和 `render_status` 同样使用 `pending`、`processing`、`done`、`failed`。

### 2.6 生成任务 `Generation`

```json
{
  "generation_id": "generation_001",
  "outline_id": "outline_001",
  "outline_version": 2,
  "status": "partial_done",
  "stage": "page",
  "progress_pct": 50,
  "current_node_id": "node_003",
  "pages": [],
  "version_id": null,
  "error": null
}
```

`status` 只允许：

```text
pending       等待处理
processing    正在处理
partial_done  部分页面完成
done          全部完成
failed        任务失败
```

`stage` 只允许：

```text
outline       大纲处理
evidence      证据整理
content       内容生成
interactive   互动内容生成
page          页面生成
preview       预览生成
done          全部完成
```

### 2.7 互动资源 `InteractiveAsset`

```json
{
  "interactive_asset_id": "asset_001",
  "generation_id": "generation_001",
  "node_id": "node_004",
  "asset_type": "html5",
  "status": "done",
  "file_url": "minio://exports/generation_001/node_004.html",
  "entry_url": "/api/v1/interactive/assets/asset_001",
  "file_size": 16064,
  "error": null
}
```

`asset_type`：`html5`、`gif`、`mp4`。

`status`：`pending`、`processing`、`done`、`failed`。

## 3. API 规范

统一前缀：

```text
/api/v1
```

### 3.1 生成大纲

```http
POST /api/v1/outlines
```

请求：

```json
{
  "session_id": "session_001",
  "intent_id": "intent_001",
  "intent": {
    "topic": "排序算法",
    "duration_minutes": 45,
    "target_student": "大一计算机专业",
    "with_interactive": true
  },
  "evidence_packet": {},
  "markdown": ""
}
```

响应：

```json
{
  "code": 200,
  "data": {
    "outline_id": "outline_001",
    "outline_version": 1,
    "status": "draft",
    "nodes": []
  }
}
```

该接口只生成大纲，不生成完整讲稿和 PPT。

### 3.2 获取大纲

```http
GET /api/v1/outlines/{outline_id}?version=1
```

响应：

```json
{
  "code": 200,
  "data": {
    "outline_id": "outline_001",
    "outline_version": 1,
    "status": "draft",
    "nodes": []
  }
}
```

### 3.3 AI 修改大纲

```http
POST /api/v1/outlines/{outline_id}/revise
```

请求：

```json
{
  "message": "增加一个生活案例，把课堂练习放到快速排序之后",
  "base_version": 1,
  "auto_apply": false
}
```

响应：

```json
{
  "code": 200,
  "data": {
    "outline_id": "outline_001",
    "outline_version": 2,
    "status": "draft",
    "change_summary": [
      "新增生活案例节点",
      "调整课堂练习顺序"
    ],
    "nodes": []
  }
}
```

`auto_apply=false` 时，返回的是待确认修改结果，不应直接进入正式生成。

### 3.4 保存大纲版本

```http
PUT /api/v1/outlines/{outline_id}
```

请求：

```json
{
  "base_version": 1,
  "nodes": [
    {
      "node_id": "node_001",
      "order": 1,
      "title": "问题导入",
      "summary": "通过生活案例引出排序问题",
      "node_type": "content",
      "key_points": ["生活案例", "排序需求"],
      "estimated_duration_minutes": 5,
      "source_chunk_ids": [],
      "interactive_plan": null
    }
  ]
}
```

后端要求：

- `base_version` 必须等于当前版本，否则返回 `409`。
- `node_id` 不得重复。
- `order` 必须从 1 连续编号。
- 必须保留原节点的 `node_id`。
- 保存后生成新的 `outline_version`。

### 3.5 确认大纲

```http
POST /api/v1/outlines/{outline_id}/confirm
```

请求：

```json
{
  "outline_version": 2
}
```

响应：

```json
{
  "code": 200,
  "data": {
    "outline_id": "outline_001",
    "outline_version": 2,
    "status": "confirmed",
    "confirmed_at": "2026-09-03T10:20:00+08:00"
  }
}
```

确认校验：

- 节点数量大于 0。
- `node_id` 不重复。
- `order` 连续且不重复。
- `title`、`summary` 不为空。
- `estimated_duration_minutes` 大于 0。
- `interactive_plan` 格式正确。
- 总时长符合教学意图约束。

### 3.6 根据确认大纲生成内容

```http
POST /api/v1/generations
```

请求：

```json
{
  "outline_id": "outline_001",
  "outline_version": 2,
  "outline_confirmed": true,
  "session_id": "session_001",
  "template_id": "default",
  "generate_mode": "page_incremental"
}
```

响应：

```json
{
  "code": 200,
  "data": {
    "generation_id": "generation_001",
    "outline_id": "outline_001",
    "outline_version": 2,
    "status": "pending",
    "stage": "content"
  }
}
```

后端和 AI Engine 都必须校验：

```text
outline_confirmed != true  → HTTP 409
outline.status != confirmed → HTTP 409
outline_version 不匹配       → HTTP 409
```

如果请求携带已确认大纲，AI Engine 必须直接使用该大纲，不得再次调用 `OutlineBuilder` 覆盖节点顺序、标题或核心要点。

## 4. 错误响应

统一错误结构：

```json
{
  "code": 409,
  "error": {
    "error_code": "OUTLINE_NOT_CONFIRMED",
    "message": "大纲尚未确认，不能开始正式生成",
    "request_id": "req_001"
  }
}
```

建议错误码：

| HTTP | `error_code` | 场景 |
|---:|---|---|
| 400 | `INVALID_REQUEST` | 请求字段缺失或类型错误 |
| 404 | `OUTLINE_NOT_FOUND` | 大纲不存在 |
| 404 | `GENERATION_NOT_FOUND` | 生成任务不存在 |
| 404 | `PAGE_NOT_FOUND` | 页面不存在 |
| 409 | `OUTLINE_NOT_CONFIRMED` | 大纲未确认 |
| 409 | `OUTLINE_VERSION_CONFLICT` | 大纲版本冲突 |
| 409 | `GENERATION_VERSION_CONFLICT` | 生成版本冲突 |
| 422 | `INVALID_OUTLINE` | 大纲结构校验失败 |
| 500 | `GENERATION_FAILED` | 内容或页面生成失败 |
| 502 | `AI_ENGINE_UNAVAILABLE` | AI Engine 不可用 |

## 5. 旧接口映射

为兼容当前实现，旧接口与新规范的关系如下：

| 当前接口 | 新规范定位 |
|---|---|
| `POST /api/v1/gen/outline` | 兼容的大纲生成接口，响应字段逐步对齐 `Outline` |
| `POST /api/v1/gen/create` | 兼容的生成接口，必须增加 `outline_id`、`outline_version`、`outline_confirmed` 支持 |
| `GET /api/v1/gen/status/{task_id}` | 兼容的任务状态接口，响应补充 `generation_id`、`outline_id`、页面状态 |
| `POST /api/v1/gen/preview` | 预览接口 |
| `GET /api/v1/gen/preview/{gen_id}` | 持久化版本预览接口 |
| `POST /api/v1/gen/modify` | 兼容的节点修改接口，后续按页面级修改接口扩展 |
| `POST /api/v1/export/{gen_id}` | 兼容的导出接口，格式字段统一为 `pptx`、`docx`、`lesson_plan`、`html5` |

新接口与旧接口并行期间，Go 后端负责对外提供统一响应，AI Engine 负责遵守本文件中的字段和状态定义。

## 6. 核心一致性要求

1. `outline_id + outline_version` 唯一确定一份大纲内容。
2. `generation_id` 必须记录实际使用的 `outline_id` 和 `outline_version`。
3. 已确认大纲不能被生成流程重新构建覆盖。
4. `node_id` 在大纲、内容节点、页面和互动资源之间保持一致。
5. 页面失败时只能将该页面置为 `failed`，不能清除其他已完成页面。
6. `progress_pct` 统一使用 0-100 百分制。
7. `task_id` 只用于轮询，不作为内容对象主键。
8. `interactive_plan` 只描述互动规划，具体互动题目放在 `interactive_items` 或互动资源中。
9. 所有新接口必须同时更新 Go 类型、Python Pydantic 模型和接口测试。
10. 任何字段变更都必须同步更新本规范和跨层契约测试。
