# 成员 B 任务说明

## 职责定位

S2 → S3 证据透传负责人。负责让 S2 知识库检索生成的证据包自动注入 S3 的 AI 生成上下文。

## 目标

- S2 生成证据包后，自动持久化到 localStorage
- S3 调用 AI 生成课件时，自动从 localStorage 读取证据包附加到请求中
- 无证据时正常降级，不报错

## 前置条件

- `materialStore.s3EvidencePayload` getter 已能返回符合后端契约格式的证据包
- `materialStore.latestEvidencePacket` 能获取最新证据包
- `teacherV1Api.coursewares.generateScript()` 需要扩展以接受 evidence 参数
- 后端生成接口需要支持 evidence 上下文（或由前端拼接后传到 AI 引擎）

## 涉及文件

### 文件 1：`src/services/v1/generationApi.js`

**改动位置**：`generateScript` 方法

**改动内容**：扩展 `generateScript` 方法，增加 `evidence` 可选参数。如果传入了 evidence，则做 base64 编码或直接 JSON 序列化后附加到请求 body 中。

```javascript
// 修改前
generateScript: (courseId, pageNum, mode = 'standard') =>
  requestJson(`/api/v1/teacher/coursewares/${courseId}/scripts/ai-generate`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ pageNum, mode })
  })

// 修改后
generateScript: (courseId, pageNum, mode = 'standard', evidence = null) => {
  const body = { pageNum, mode }
  if (evidence) {
    body.evidence = evidence
  }
  return requestJson(`/api/v1/teacher/coursewares/${courseId}/scripts/ai-generate`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(body)
  })
}
```

**注意事项**：
- evidence 参数为可选，不传时行为与原来完全一致
- 保持向后兼容：已有调用方不需要修改
- 证据包格式与后端约定一致

### 文件 2：`src/pages/S3StudioPage.vue`

**改动位置**：`handleGenerateAIScript` 方法中调用 `generateScript` 之前

**改动内容**：调用 AI 生成前，从 localStorage 读取证据包，如果有则传入。

```javascript
// 添加位置：在 handleGenerateAIScript 方法中，调用 generateScript 之前
// 尝试从 localStorage 读取证据包
let evidence = null
try {
  const raw = localStorage.getItem('fuww_s2_evidence_packet')
  if (raw) {
    evidence = JSON.parse(raw)
    console.log('[S3StudioPage] 从 localStorage 读取证据包:', evidence)
  }
} catch (e) {
  console.warn('[S3StudioPage] 读取证据包失败', e)
}

// 修改 generateScript 调用
const result = await teacherV1Api.coursewares.generateScript(
  courseId.value,
  pageNum.value,
  'standard',
  evidence  // 新增：传入证据包
)
```

**注意事项**：
- JSON.parse 需要 try-catch
- 无证据时正常调用，不报错
- 证据包较大时考虑截断或摘要

### 文件 3（可选）：`src/stores/materialStore.js`

**改动位置**：`addEvidencePacket` 或 `generateEvidence` 方法中

**改动内容**：在证据包生成时同步写入 localStorage。如果 materialStore 已有此逻辑则跳过。

```javascript
// 在 addEvidencePacket 或 generateEvidence 的成功分支中添加
// 写入 localStorage 供 S3 读取
if (packet && packet.packet) {
  localStorage.setItem('fuww_s2_evidence_packet', JSON.stringify(packet.packet))
}
```

## 数据契约

### localStorage Key

| Key | 类型 | 写入时机 | 读取时机 |
|-----|------|---------|---------|
| `fuww_s2_evidence_packet` | JSON string | 证据包生成/绑定时 | S3 调用 AI 生成前 |

### 证据包格式（materialStore.s3EvidencePayload 返回格式）

```json
{
  "relevant_chunks": [
    {
      "chunk_id": "chunk_001",
      "material_id": "mat_001",
      "content": "二次函数 y=ax²+bx+c 的图像是一条抛物线...",
      "source": "教材第三章.pdf",
      "relevance_score": 0.92
    }
  ],
  "synthesized_context": "基于检索结果，关键知识点包括：二次函数的标准形式、开口方向判断、顶点坐标公式...",
  "citations": [
    { "source": "教材第三章.pdf", "page": 15, "chunk_ids": ["chunk_001"] }
  ]
}
```
