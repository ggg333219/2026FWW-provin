真机实测方案：S1→S4 全链路手动验收
环境准备
条件	说明
浏览器	Chrome/Edge，打开 http://localhost:5173
开发者工具	F12 → Application 面板 + Network 面板
测试课件	ID 3be64dfe-5ef7-4a6b-a0c7-0635fd69d6d4（已有 28 页）
测试账号	新注册或 demo_teacher / 123456
第一轮：注册 + 登录

1. 打开 http://localhost:5173 → 自动跳转 /login
2. 点"注册"标签 → 输入用户名 + 密码 → 点"注册"
   ✓ Network 看 POST /api/v1/auth/register → 200
3. 切到"登录" → 输入同上 → 点"登录"
   ✓ 自动跳转 /middle（中间页）
   ✓ Application → Local Storage 有 fuww_teacher_logged_in
第二轮：S1 意图理解

1. 在中间页（/middle）点"新建课件" → 进入 S1IntentPage
2. 在对话框输入教学目标（如"讲解二次函数图像特征"）→ 发送
3. AI 回复 → 确认意图
4. 点底部"下一步：进入 S2 素材 →"
   ✓ 跳转到 /courseware/create/s2-material
第三轮：S2 素材 + 证据生成（核心）

1. 在 S2MaterialPage 上传资料（点"上传"或拖拽）
2. 上传后点"索引知识库" → 等待索引完成
3. 在搜索框输入查询词（如"二次函数"）→ 点搜索/检索
4. 点"生成证据包"或检索后自动生成
   ✓ Application → Local Storage → fuww_s2_evidence_packet 出现
   ✓ 展开看内容：含 query、relevant_chunks、synthesized_context
5. 截图保存：Application 面板显示 evidence packet
6. 点底部"下一步：进入 S3 生成 →"
   ✓ 跳转到 /workspace，自动切到"编辑讲稿" Tab
第四轮：S3 讲稿生成 + 证据透传（核心）

1. 在 Workspace 页面，确认顶部显示课件名称和页码
2. 确认左侧菜单选中"编辑讲稿"（script Tab）
3. 找到"AI 生成脚本"按钮 → 点击
   ✓ Network 面板找到 POST .../ai-generate 请求
   ✓ 点开请求 → Payload 标签 → 确认 body 含 evidence 字段
   ✓ evidence.query 有值
   ✓ evidence.relevant_chunks 数组长度 > 0
4. 等待生成完成 → 看右侧"讲稿编辑"面板
   ✓ "整页讲稿"区块渲染出讲稿文本
   ✓ 讲稿含「📋 证据上下文」段落
   ✓ 讲稿含「参考资料」段落
5. 截图：Network 面板 evidence body + 讲稿编辑器含证据段落
第五轮：无证据降级验证

1. 在 Application → Local Storage 中删除 fuww_s2_evidence_packet
2. 刷新页面（F5），回到 Workspace 编辑讲稿 Tab
3. 再次点击"AI 生成脚本"
   ✓ Network 面板 ai-generate 请求 body 不含 evidence 字段
   ✓ 请求正常返回 200，讲稿正常生成（无证据段落）
第六轮：S4 版本管理

1. 在 Workspace 左侧菜单切到"版本管理" Tab
2. 输入 Generation ID
3. 点"加载版本" → 确认版本历史列表渲染
4. 测试版本回滚（如有可回滚版本）
第七轮：Workspace 内跨 Tab 导航

1. 确认左侧菜单所有 Tab 可切换：
   - 编辑讲稿（script）
   - 数据统计（stats）
   - 学生提问（questions）
   - 迭代优化（iteration）
   - 知识图谱（knowledge）
   - 意图理解（intent）
   - 资料中心（material）→ 有"下一步"按钮 → 点它切回 script
   - 版本管理（version）
