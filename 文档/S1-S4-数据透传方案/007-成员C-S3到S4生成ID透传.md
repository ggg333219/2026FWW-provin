# 成员 C 任务说明

## 职责定位

S3 → S4 gen_id 透传负责人。负责让 S3 生成的 gen_id 自动带到 S4 版本管理页面。

## 目标

- generationStore 增加 `lastGenId` 字段存储最新生成 ID
- S3 生成完成后自动持久化 gen_id 到 localStorage
- S4 页面加载时自动从 generationStore / localStorage 读取 gen_id

## 前置条件

- S3 生成完成后，后端返回 `gen_id` 或 `genId` 字段
- S4VersionPage 已有 `genIdInput` 或 `genId` ref 控制输入框
- versionStore 已有 `genId` state 字段

## 涉及文件

### 文件 1：`src/stores/generationStore.js`

**改动位置**：`state` 部分和 actions 部分

**改动内容**：增加 `lastGenId` 字段和 setter action。

```javascript
// state 中增加
state: () => ({
  currentScript: '',
  currentScriptNodes: [],
  lastGenId: '',  // ← 新增：最新生成 ID
  // ... 已有字段保持不变
})

// actions 中增加
actions: {
  // ... 已有 actions 保持不变

  // 新增：设置 lastGenId
  setLastGenId(genId) {
    this.lastGenId = genId
    // 同步写入 localStorage
    if (genId) {
      localStorage.setItem('fuww_last_gen_id', genId)
    }
  },

  // 可选：从 localStorage 恢复 lastGenId
  restoreLastGenId() {
    if (!this.lastGenId) {
      try {
        const cached = localStorage.getItem('fuww_last_gen_id')
        if (cached) {
          this.lastGenId = cached
        }
      } catch (e) {
        console.warn('[generationStore] 恢复 lastGenId 失败', e)
      }
    }
    return this.lastGenId
  }
}
```

**注意事项**：
- 字段名 `lastGenId` 不与已有字段冲突
- 写入 localStorage 时同时写入 Store
- 不需要在 reset 中清除（或者保留不清除，让用户主动覆盖）

### 文件 2：`src/pages/S3StudioPage.vue`

**改动位置**：生成完成后，获取 gen_id 的位置

**改动内容**：在 AI 生成成功回调中，从返回结果提取 gen_id 并写入 generationStore。

```javascript
// 在 handleGenerateAIScript 的成功回调中
// 获取 gen_id 并写入 generationStore
const generationStore = useGenerationStore()

// 在生成成功后（假设返回结果中有 genId 或 gen_id 字段）
const genId = result?.genId || result?.gen_id || ''
if (genId) {
  generationStore.setLastGenId(genId)
}
```

**注意事项**：
- 确认后端返回的字段名（genId 或 gen_id）
- 生成失败时不写入
- 不阻塞主流程

### 文件 3：`src/pages/S4VersionPage.vue`

**改动位置**：`onMounted` 或 `genIdInput` 初始化位置

**改动内容**：页面加载时从 generationStore 读取 lastGenId，如果为空则从 localStorage 读取。

```javascript
// 修改位置：在 setup 中初始化 genIdInput 的位置
import { useGenerationStore } from '@/stores/generationStore'

const generationStore = useGenerationStore()

// 尝试从 generationStore 获取 lastGenId
let initialGenId = generationStore.lastGenId || ''

// 如果 Store 中没有，尝试从 localStorage 恢复
if (!initialGenId) {
  initialGenId = generationStore.restoreLastGenId()
}

// 如果还没有，回退到 workspaceStore.currentCourseId
const genIdInput = ref(initialGenId || workspaceStore.currentCourseId || '')
```

**注意事项**：
- 优先级：generationStore.lastGenId > localStorage > workspaceStore.currentCourseId > 空字符串
- 用户手动输入后不清除（不覆盖用户输入）
- 空数据时正常显示空输入框，不报错

## 数据契约

### localStorage Key

| Key | 类型 | 写入时机 | 读取时机 |
|-----|------|---------|---------|
| `fuww_last_gen_id` | string | S3 生成成功时 | S4 页面加载时 |

### 数据格式

```
gen_abc123def456
```

（纯字符串，非 JSON）
