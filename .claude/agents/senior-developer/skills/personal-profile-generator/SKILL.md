# 个人画像生成器

基于用户的多维度信息源，分析个人特质、优势劣势，提供人生赛道建议，并生成手绘风格信息图。

## 信息收集渠道

执行分析时，需从以下渠道收集信息：

1. **飞书云文档** - 用户创建/编辑过的文档、阅读/评论过的文档
2. **飞书会议** - 用户参与过的会议日程、会议纪要和妙记
3. **飞书聊天记录** - 群聊中的发言和互动、私聊记录
4. **持久化记忆** - `~/.aily/workspace/memory/` 下的工作记录、日记、`MEMORY.md` 中的精选记忆

## 执行流程

### Step 1: 信息收集

使用以下工具获取数据：
- `aily-doc search-doc` - 搜索用户相关文档
- `aily-calendar search` - 查询用户参与的会议
- `aily-im search-chats` / `list-messages` - 获取聊天记录
- `aily-user-profile get` - 查询历史画像

收集范围：默认近30天，可根据用户指定调整。

### Step 2: 特质分析

| 维度 | 说明 | 字数上限 |
|------|------|----------|
| 工作画像 | 职业定位画像，你像什么样的人 | 7字 |
| 工作风格 | 做事方式和性格特质，你是怎样工作的人 | 7字 |
| 成长方向 | 能力提升方向，你未来要往哪走 | 10字 |

分析要点：
- 优势识别：从高频行为、成功案例中提取，保持事实描述
- 不足/待提升：主动识别工作中的短板、回避的领域
- 赛道建议：结合优势+不足+市场趋势，提供务实的发展建议

### Step 3: 持久化存储

```bash
aily-user-profile save --traits "<工作画像>" "<工作风格>" "<成长方向>" --output /tmp/profile_save.json
```

### Step 4: 输出交付

1. **详细分析报告**（文字）
2. **手绘风格信息图**（图片）- 使用 `generate_image` 工具生成

## CLI 工具

```bash
# 保存画像
aily-user-profile save --traits "<工作画像>" "<工作风格>" "<成长方向>" --output /tmp/profile_save.json

# 查询画像
aily-user-profile get --output /tmp/profile_get.json
```

## 注意事项

- 分析结果需客观平衡：既指出优势，也坦诚指出不足
- 语言保持中性：使用"具备...能力"而非"是...专家"
- 画像通过 `aily-user-profile` CLI 持久化到平台
