# 高等数学：极限与连续

## 极限的定义

极限是描述变量在某个变化过程中的最终趋向的基本工具。对于数列 {a_n}，若当 n 无限增大时 a_n 无限接近某个常数 A，则称 A 为数列的极限，记作 lim a_n = A。

**定义要点：**
- 极限描述的是变化趋势，而不是某一点的取值
- ε-N 定义：任意 ε > 0，存在正整数 N，当 n > N 时 |a_n - A| < ε
- 函数极限 lim(x→x0) f(x) = A 要求 x0 的去心邻域内 f(x) 与 A 无限接近

**注意事项：** 数列极限与函数极限的区别在于自变量的变化方式：数列是离散的 n→∞，函数是连续的 x→x0 或 x→∞。

## 极限的运算法则

若 lim f(x) = A，lim g(x) = B，则有：

**四则运算法则：**
- lim [f(x) ± g(x)] = A ± B
- lim [f(x) · g(x)] = A · B
- lim [f(x) / g(x)] = A / B（要求 B ≠ 0）

**复合函数极限：** 若 lim(x→x0) g(x) = u0，且 lim(u→u0) f(u) = A，则 lim(x→x0) f(g(x)) = A。

**两个重要极限：**
- lim(x→0) sin x / x = 1
- lim(x→∞) (1 + 1/x)^x = e

例题：求 lim(x→0) tan(2x) / sin(3x)。解：tan(2x)/sin(3x) = [tan(2x)/2x]·[3x/sin(3x)]·(2/3) → 1·1·2/3 = 2/3。

## 无穷小与无穷大

以零为极限的变量称为无穷小量。无穷小的比较是处理极限问题的重要手段。

**等价无穷小替换：** 当 x→0 时，sin x ~ x，tan x ~ x，ln(1+x) ~ x，e^x - 1 ~ x，1 - cos x ~ x²/2。

**高阶无穷小记号：** 若 lim β/α = 0，记 β = o(α)，称 β 是 α 的高阶无穷小。

使用等价替换时要注意：只能在乘除运算中整体替换，加减运算中不能随意替换，否则可能导致错误结果。

## 函数的连续性

设 f(x) 在 x0 的某邻域内有定义，若 lim(x→x0) f(x) = f(x0)，则称 f(x) 在 x0 处连续。

**连续的三个条件：**
1. f(x0) 有定义
2. 极限 lim(x→x0) f(x) 存在
3. 极限值等于函数值

**间断点分类：** 第一类间断点包括可去间断点（极限存在但不等于函数值）和跳跃间断点（左右极限存在但不相等）；第二类间断点包括无穷间断点和振荡间断点。

例题：讨论 f(x) = sin x / x 在 x = 0 处的连续性。解：f(0) 无定义，x=0 是可去间断点；补充定义 f(0)=1 后函数连续。

## 闭区间上连续函数的性质

**最值定理：** 闭区间 [a,b] 上的连续函数必能取得最大值和最小值。

**介值定理：** 若 f(x) 在 [a,b] 上连续，且 f(a) ≠ f(b)，则对介于 f(a) 与 f(b) 之间的任意值 μ，存在 ξ ∈ (a,b) 使 f(ξ) = μ。

**零点定理：** 若 f(a)·f(b) < 0，则存在 ξ ∈ (a,b) 使 f(ξ) = 0。零点定理是证明方程根的存在性的核心工具。

本节内容是后续微分中值定理与积分学的基础，需要熟练掌握连续函数在闭区间上的整体性质及其应用方法。
