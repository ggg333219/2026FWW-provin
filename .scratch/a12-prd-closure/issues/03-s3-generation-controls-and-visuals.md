# S3 生成模式、大纲与页面呈现

Status: ready-for-agent
Triage: ready-for-agent

## Goal

打通教师选择生成范围、编辑大纲、逐页生成以及统一控制 PPT 页面呈现和配图的真实工作流。

## Acceptance Criteria

- S3 提供同页模式选择和同一生成操作：“内容生成”只按已确认大纲生成/更新页面；“全流程生成”从意图和资料开始生成大纲与内容。
- AI 大纲生成支持可观察进度；现有超时/回退契约继续生效，手工编辑、增删、排序后可持久化保存。
- 默认生成封面和总结页；目录按已确认的节点数量规则生成，并保留必要的教师覆盖能力。
- 内容概述不作为 PPT 正文重复显示。
- 逐页模式逐个调用真实页面内容生成；显示目标页状态，失败时不丢失其他已完成页面。
- 疏密选择在 HTML/SVG 预览和 PPTX 导出中使用同一规范值与视觉参数。
- 配图优先使用本地/内置素材；无合适素材时尝试 LLM 生图；生图不可用不阻塞课件生成，引用素材随课件资产持久化。

## Test Seam

对已确认大纲分别执行两种模式和逐页模式，检查生成范围与页面状态；使用同一组节点和密度比较预览规格与 PPTX 页面；以本地素材命中、无素材生图成功和生图失败三种确定性 fixture 验证配图回退。
