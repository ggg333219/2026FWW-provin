# 平台共享知识库、证据筛选与生成指令集

Status: ready-for-agent
Triage: ready-for-agent

## Goal

完成平台共享知识库的持久化、S2 全量候选证据筛选和跨生成阶段复用的结构化生成指令集。项目既有“平台共享知识库”领域术语是本 issue 的边界，不实现教师私有知识库替代方案。

## Acceptance Criteria

- 授权教师可复用平台共享资料；补充资料的上传、来源、切片、索引和状态在服务重启后仍能查询与检索。
- 已确认片段以内容和来源快照进入当前课件项目；未确认的候选片段不会被当作生成依据。
- S2 可搜索、筛选、分页浏览完整候选集；筛选和选择不被前十条限制。
- 结构化生成指令集汇总意图、参考资料提取、已确认片段/引用及输出要求，提供给大纲、PPT、DOCX 和互动生成。
- 指令集随项目草稿与生成结果版本留存；后续草稿更新不改变历史生成结果的指令集快照。
- 外部 API 错误、资料权限和来源引用行为遵循现有平台共享知识库、认证用户和历史证据快照约定。

## Test Seam

通过知识库 API 写入资料、重启 AI Engine/Go 后再次检索；通过生成 API 验证完整证据选择结果与同一指令集被各生成阶段消费；验证旧版本快照不随草稿更新变化。

## Existing Specs

- `.scratch/s3-gap-completion/spec.md`：复用资料/切片/证据持久化和引用协议；其个人知识库措辞需按本次确认的“平台共享知识库”决策解释，不新增私有库。
- `.scratch/member-b-ai-engine/spec.md`：复用 RAG 搜索与来源元数据契约。
