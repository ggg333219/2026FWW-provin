## 第 1 章 · 项目身份与目标

| 项 | 值 |
|---|---|
| 赛题 | 锐捷网络 · 服务外包赛题 **A12 多模态 AI 互动式教学智能体** |
| 一句话 | 把"泛雅 AI 智课系统"（讲授型课件 + 学生 Q&A）重构为**教师多轮对话 → 多模态资料融合 → 智能课件生成 → 预览修改 → 版本导出**的智能体 |
| 三层架构 | Vue3 教师端 ↔ Go 后端 ↔ Python AI Engine |
| 数据层 | PostgreSQL + Redis + MinIO（+ pgvector 可选） |
| 代码规模 | Go 85 文件 / Python 124 文件 / Vue 42 文件 |

### 1.1 业务主流程（S1→S4）

```
S1 意图理解     教师文字/语音输入 → 多轮对话澄清 → 结构化意图（IntentSummary）
S2 多模态交互   上传 PDF/PPTX/DOCX/图片/视频 → 解析 → 切片 → 知识库 RAG → 证据包
S3 课件生成     确认大纲 → 逐节点内容生成 → 页面管理 → 互动资源
S4 个性化满足   预览 → 修改命令 → 版本快照/回滚/锁定 → 导出 PPTX/DOCX/HTML5
```

### 1.2 跨层原则（改代码前必读）

- **层隔离**：Go 负责编排与网关，Skill 逻辑在 Python；Skill 之间不直接调用
- **默认异步**：解析/生成/导出走后台任务，API 立即返回 `task_id`，前端轮询
- **证据协议**：生成调用接收 `evidence_packet`，输出携带 `citation_refs[]`
- **版本边界**：Skill 产生内容，版本模块负责快照
- **字段只增不删**：跨层契约字段废弃先标 deprecated 保留一个迭代周期

`decode.js` 已存在（`C:\Users\34511\.local\aliyun-cli\decode.js`），输出 STATUS / EXITCODE / 解码后的 stdout。

**云助手踩坑**：
- 命令内容 base64 后 ≤24KB；实测原始 18000 字符可过，22000 失败 → 大文件分块传
- Git Bash 会改写 `/root/x` 这类参数 → 加 `MSYS_NO_PATHCONV=1`
- 状态 Running → Success/Failed；"Success" ≠ "Finished"，轮询判断要包含两者

### 3.5 启停命令（完整版）

```bash
# ── 停止 ──
pkill -f teacher-server-linux
pkill -f "uvicorn main:app"
nginx -s stop -c /opt/a12teaching/deploy/nginx/a12.conf

# ── 启动 AI 引擎（ASR 用本地 whisper，必须带这些环境变量）──
cd /opt/a12teaching/ai_engine
setsid nohup env PYTHONPATH=/opt/a12teaching \
  MINIO_ENDPOINT=127.0.0.1:19000 MINIO_ACCESS_KEY=minioadmin MINIO_SECRET_KEY=minioadmin MINIO_BUCKET=teaching \
  ASR_ALLOW_LOCAL_WHISPER=1 ASR_WHISPER_MODEL=tiny HF_ENDPOINT=https://hf-mirror.com \
  .venv/bin/python -m uvicorn main:app --host 127.0.0.1 --port 18000 \
  < /dev/null > /tmp/ai_a12.log 2>&1 &

# ── 启动 Go 后端（A12_PROJECT_ROOT 必配！）──
cd /opt/a12teaching/backend
setsid nohup env A12_PROJECT_ROOT=/opt/a12teaching/backend CONFIG_FILE=config.server.yaml \
  /opt/a12teaching/deploy/teacher-server-linux < /dev/null > /tmp/backend_a12.log 2>&1 &

# ── 启动 nginx ──
nginx -c /opt/a12teaching/deploy/nginx/a12.conf

# ── 启动自建 PG（服务器重启后需手动拉起）──
su -s /bin/bash postgres -c "/usr/bin/pg_ctl -D /var/lib/pgsql/a12_data \
  -o '-p 15433 -c listen_addresses=127.0.0.1 -k /tmp' -l /tmp/pg_a12.log start"

# ── 启动自建 MinIO ──
MINIO_ACCESS_KEY=minioadmin MINIO_SECRET_KEY=minioadmin setsid nohup \
  /usr/local/bin/minio server /opt/a12teaching/data/minio \
  --address :19000 --console-address :19001 < /dev/null > /tmp/minio_a12.log 2>&1 &
```

**关键点**：`setsid nohup ... < /dev/null > log 2>&1 &` 三件套必须完整——云助手命令结束会回收子进程组，少一样进程就活不过会话。

### 3.6 更新部署流程

```bash
# ── 本地 ──
# 1) 改后端：交叉编译（Windows → linux）
cd backend && CGO_ENABLED=0 GOOS=linux GOARmd64 go build -o ../deploy/teacher-server-linux ./cmd/teacher
# 2) 改前端：用相对地址构建（换端口无需重建）
cd frontend/teacher && VITE_API_BASE='' VITE_AI_API_BASE='/ai' npm run build
# 3) 提交产物（.gitignore 忽略了 dist，需 -f 强制）
git add -f deploy/teacher-server-linux frontend/teacher/dist
git commit -m "deploy: 产物更新"
git push gitcode server-deploy      # 产物走 gitcode（服务器连 GitHub 不稳）

# ── 服务器 ──
cd /opt/a12teaching
git fetch origin server-deploy && git reset --hard FETCH_HEAD
chmod +x deploy/teacher-server-linux     # ★ git 不保留可执行位，每次 reset 后必须 chmod
# 按 3.5 重启对应进程
```

**两个必踩的坑**：
1. `git reset --hard` 会还原二进制的文件权限（git 只存 644）→ 必须重新 `chmod +x`
2. 交叉编译会把**构建机路径**烧进二进制（`runtime.Caller`）→ 必须用 `A12_PROJECT_ROOT` 环境变量覆盖，否则找不到配置文件

## 第 5 章 · 核心机制说明

### 5.1 PPT 生成链路（M3 后）

```
节点数组（大纲/生成结果）
   ↓
polish_nodes（内容润色）+ run_full_check（质量检查）
   ↓
expand_deck_pages（★M3 注入：封面 → 目录(内容>5) → 原内容 → 总结）
   ↓
每个节点 → build_page_spec(node, index) → PageSpec
   ↓                                    ↓
svg_renderer.render_page_spec_to_svg   export_ppt 各页型处理器（python-pptx）
   ↓                                    ↓
预览 HTML（前端 iframe）                 PPTX 文件
```

**关键约束**：
- 预览与导出**必须**共享 `page_spec` + `deck_structure`，两端版式不能各写各的
- 合成节点 `node_id` 以 `__auto_` 开头（cover/toc/summary），前端"改一页换一页"按 `data-node-id` 定位不会冲突
- 密度（H5）与样式（presentation）参数表都是"单一来源、两端读取"

### 5.2 语音输入链路（H2）

```
浏览器 MediaRecorder 录音（全浏览器通用）
  → POST /ai/api/v1/asr/transcribe（multipart ≤20MB）
  → ai_engine/asr.py provider 链：
       ① dashscope（有 DASHSCOPE_API_KEY/AI_API_KEY → Paraformer 云端）
       ② local_whisper（ASR_ALLOW_LOCAL_WHISPER=1 → faster-whisper tiny int8 CPU）
       ③ 无 → 501 ASR_NOT_CONFIGURED
  → {text} 回填输入框
```

- **刻意不用 Web Speech API**：它绑定 Chrome/Edge 且依赖 Google 识别服务（国内不可用）
- **麦克风需要安全上下文**：只有 HTTPS 或 localhost 能用，HTTP 页面按钮会提示（用户已要求异常静默，仅控制台留痕）
- 测试：`deploy/testdata/voice-test-zh.wav`，`curl -F "file=@voice-test-zh.wav;type=audio/wav" -F "language=zh" .../api/v1/asr/transcribe`
- 实测：tiny 模型中文短句准确，首调 ~18s（加载模型），此后 ~1s

### 5.3 后端降级策略

`cmd/teacher/main.go` 启动时探测依赖，任一不可用即降级：

| 条件 | 行为 |
|---|---|
| DB 连不上 | `runS1Standalone` — 只提供 S1 轻量路由，无持久化 |
| MinIO 连不上 | 同上 |
| AI 引擎无 LLM key | 引擎内部降级：S1 走规则引擎、S3 走模板 mock，响应带 `degraded:true` |

**降级不是故障**：验收流程在无 key 情况下全链路可跑通（大纲→生成→导出 PPTX 真文件）。

### 5.4 鉴权与项目归属

- 登录：`POST /api/v1/auth/login` → 返回 `authToken`（注意字段名，不是 `token`）
- 受保护接口需 `Authorization: Bearer <authToken>`
- **导出按项目归属鉴权**：`POST /api/v1/export/:gen_id` 要求该 generation 已通过 `project_id` 绑定到当前用户的课件项目（`gen/create` 带 `project_id` 时自动绑定）。直接用引擎生成的大纲不绑定项目 → 导出返回 404「课件不存在」，这是**设计如此**不是 bug

## 附录 B · 数据模型要点

### B.1 ID 链路（S3 数据规范 v1.0）

```
session_id → intent_id → outline_id + outline_version → generation_id → version_id → page_id + node_id → interactive_asset_id
```

`task_id` 只用于轮询，不作为内容对象主键。

### B.2 状态机

| 对象 | 取值 |
|---|---|
| 大纲 status | `draft` / `confirmed` / `superseded` |
| 生成 status | `pending` / `processing` / `partial_done` / `done` / `failed` |
| 生成 stage | `outline` / `evidence` / `content` / `interactive` / `page` / `preview` / `done` |
| 页面 status | `pending` / `processing` / `done` / `failed` |
| 导出 status | `pending` / `exporting` / `done` / `failed` |

### B.3 字段命名铁律

- `snake_case`；`node_id` 不用 `nodeId`；`generation_id` 不用 `gen_id` 作主字段
- `estimated_duration_minutes`（分钟）
- `key_points` / `questions` 为**字符串数组**
- `progress_pct` 用 0-100 百分制
