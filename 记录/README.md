# 项目协作模型 & 记录系统使用说明

## 一句话

这个项目用 **5 个文件** 串起三个人的并行工作，不需要开会、不需要拉群。

---

## 五文件协作模型

```
文档/000-README.md          大方向：项目定位、技术栈、7 层架构
文档/001-分工方案-总览.md    定做什么：每人任务清单 + 模块职责
文档/005-接口契约手册.md     怎么连：跨层 API 定义 + 数据模型
记录/汇报/P{任务}.md         做完了：谁干了什么、改了啥、下一步谁接
记录/决策日志/D-xxx.md       为什么：方案选择、设计讨论
```

| 文件 | 什么时候看/写 | 谁维护 |
|------|-------------|--------|
| `000-README.md` | 开工前看一次，迷路了回来看 | 协调人 |
| `001-分工方案-总览.md` | 每天开工看自己的任务包 | 协调人初始，各自更新 |
| `005-接口契约手册.md` | A↔B 联调前一起过 | 改接口的人更新 |
| `汇报/` | **做完一个子任务写一次** | 各人维护自己的 |
| `决策日志/` | 做方案选择时写 | 谁决策谁写 |

## 记录系统总览

```
记录/
├── README.md              ← 使用说明（本文件）
├── 进度跟踪/README.md      ← 进度看板：各 Phase 任务完成情况
├── 汇报/README.md          ← 汇报模板 + 3 个例子
├── 汇报/P3-A1-xxx.md       ← 你填的具体汇报（每个子任务一份）
├── 决策日志/D-xxx.md       ← 设计方案选择记录
└── 周报/模板.md             ← 周报模板
```

## 日常节奏

### 每做完一个子任务 → 填汇报

````
复制 记录/汇报/README.md 里的模板，填 10 个字段：

task_id: P3-A1        # 阶段-任务编号
title: 死代码清理       # 中文名
author: 同学 A         # 你
date: 2026-07-18       # 完成日期
status: completed      # completed | partial | blocked | failed
summary: >             # 一句话给下一个人看——最重要的字段
  做了什么、结果怎样
changes:               # 改了什么文件
  created:
    - xxx
  modified:
    - xxx
  deleted:
    - xxx
affects: A             # 影响谁？A | B | C | AB | BC | ABC | 无
next: >                # 下一步指引
  谁接、从哪开始、注意什么
---
````

关键原则：**summary 和 next 是给人看的**，其他字段是给 AI 扫的。
填完存到 `记录/汇报/P{阶段}-{任务编号}-{标题}.md`，推上去就行。

### 每天 → 看一眼进度

看一眼 `记录/进度跟踪/README.md`，知道大家做到哪了。

### 遇到方案选择 → 写决策日志

复制 `记录/决策日志/README.md` 里的模板：
````
## D-{序号} {日期} - {决策标题}

### 背景
为什么需要做这个决策？

### 可选方案
列出考虑过的方案及各自优劣势。

### 决策结论
最终选择了什么，为什么。

### 影响范围
影响哪些模块/文件/队友。
````

### 每周五 → 写周报 + 看别人汇报

1. 复制 `记录/周报/模板.md` 创建当周周报，填你这周做了什么
2. 扫一遍 `记录/汇报/` 看看其他人这周填了什么

## 分支策略

```
main              ← 稳定分支，保护
ppt               ← PPT 相关改动
develop           ← 日常开发
feature/*         ← 功能分支
```

- 每个人在自己分支上开发
- 做完子任务 → 填汇报 → 推到自己的分支
- 协调人定期合并到 main

---

## 三个角色

| 角色 | 负责 | 任务包 |
|------|------|--------|
| **A - Go 后端** | API、数据库、会话管理、文件服务 | `文档/002-任务包-Go后端-A.md` |
| **B - Python AI 引擎** | LLM 封装、4 Skill、知识库 RAG | `文档/003-任务包-PythonAI引擎-B.md` |
| **C - Vue 前端** | 路由、对话视图、课件编辑、资料管理 | `文档/004-任务包-Vue前端-C.md` |

A 和 B 联调前必须先一起看 `文档/005-接口契约手册.md`。

---

## 一句话总结

> **README 定方向 → 任务包定做什么 → 接口契约定怎么连 → 汇报定进度 → 决策日志定为什么**

做完就写，写了就推，推了就看别人写的。这就是全部规则。
