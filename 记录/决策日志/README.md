# 决策日志

## 用途

记录本项目二次开发全过程中所有关键决策、方案选择、设计讨论及其依据。
用于终期答辩时追溯设计思路，确保"从头到尾的决策过程有记录可查"。

## 格式

每条决策记录含：

```markdown
## D-{序号} {日期} - {决策标题}

### 背景
为什么需要做这个决策？当前面临什么问题或约束？

### 可选方案
列出考虑过的方案及各自优劣势。

### 决策结论
最终选择的方案及理由。

### 影响范围
该决策影响哪些模块/文件/团队分工。

### 验证方式
如何验证该决策是正确的？（测试用例/评审/指标）
```
