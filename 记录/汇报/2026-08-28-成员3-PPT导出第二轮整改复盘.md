# 成员3：PPT 导出第二轮整改复盘

## 一、本轮认领范围

本轮只处理 PPT 导出与模板适配，不修改底层 Schema，也不修改前端预览核心渲染逻辑。根据上一轮复盘，优先完成两个未闭环事项：

1. 将 `two_column` 从 `content` 别名升级为真实双栏版式；
2. 生成全版式兼容测试稿并完成 WPS 实机验收。

## 二、已完成工作

### 1. 真双栏版式

- `node_type/type = two_column` 现在解析为独立页面类型；
- 左栏固定承载 `key_points/core_points`；
- 右栏优先承载 `segments`，缺失时回退到 `content/script`；
- 左右栏分别分块并生成续页，避免长文本互相挤压；
- 新增坐标级测试，验证左右文本确实位于不同区域。

### 2. 模板体系同步

- `default / academic / minimal` 三套模板全部重新构建；
- 模板样例从四类页面补齐到五类，新增 `two_column`；
- README 明确 `content` 与 `two_column` 的语义差异和回退规则。

### 3. 兼容性验收

- 新增 `scripts/generate_wps_compat_deck.py`，一键生成 7 页全版式测试稿；
- 自动渲染并人工检查全部 7 页；
- 在 WPS Office 12.1.0.28043 中真实打开；
- 留存封面、内容/segments、真双栏、总结四张实机截图；
- OOXML 结构检查确认 0 个图片形状、73 个原生文本形状，不是图片伪导出；
- PowerPoint Office16 进程可启动，但本机未出现可交互主文档窗口，因此未虚报 Office 实机通过。

## 四、当前剩余风险

1. 需要在另一台能正常显示 PowerPoint 主文档窗口的 Office 2016+ 环境补一次人工交叉打开；
2. Windows 渲染辅助器会在 PNG 已全部生成后错误返回失败码，后续可单独修辅助器，但不应阻塞 PPT 导出交付；
3. `two_column` 的极端长文本仍应持续用多主题、多字号样本回归。
