# Slidev 答辩草稿

这份目录下的 `slides.md` 是按答辩主线整理的 20 页 Slidev 草稿，结构为：

- 封面 1 页
- 背景 1 页
- 痛点分析 1 页
- 系统架构 2 页
- 算法设计若干页
- 场景案例若干页
- 验证、创新点、取舍、后续工作、致谢

## 使用方式

如果本机已经安装了 Slidev，可以直接在这个目录里运行：

```bash
npx slidev@latest slides.md
```

导出 PDF 可以使用：

```bash
npx slidev@latest export slides.md
```

1. 先补视觉主题，让它更像正式答辩 PPT。
2. 再给每一页补更短的讲稿备注，方便现场脱稿。
